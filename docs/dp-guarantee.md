# 差分プライバシーの保証の根拠と限界

GHE issue 22の成果物。GHE issue 14・18で、差分プライバシー（DP）付きの合成データを作り、「εの保証がある」と書いた。その保証が何を根拠に成り立ち、どこには及ばないかを示す。手順は [synthesis-methods.md](synthesis-methods.md) の7節。

## 結論

- **保証は、手順そのものについて数学的に成り立つ。** 被験者1人を別の人に入れ替えても、合成データの分布は (ε, δ) の範囲でしか変わらない。根拠は、被験者ごとの寄与を公開の定数で有界にしたこと、ガウス機構、zCDPの合成定理、後処理の不変性の4つで、どれも標準的な定理である（Dwork & Roth 2014; Bun & Steinke 2016）。
- **実装がこの前提を満たすことは、テストで確かめた。** どんな被験者に入れ替えても、雑音を加える前の総和の変化は決めた感度の上界に収まり（最悪で上界の50〜95%）、生成は雑音を加えた総和だけを使っていた。
- **ただし保証は条件付きで、次の場合には及ばない。** 同じ人が複数の記録を持つ場合、公開の範囲や ε をデータを見て決めた場合、同じデータから何度も公開する場合、浮動小数点の実装の弱点を突かれる場合。今回の eICU Demo では同じ患者が最大5回入室しており、滞在単位の ε = 4 は、その患者にとって ε = 26 に当たる。
- **時系列の生体データに有用な保証を付けるのは、数十人では難しい。** 保証自体は付けられるが、被験者ごとの寄与を有界にするために統計量を絞り、雑音を人数で割ることになり、数十人では見本として使えない質になった（GHE issue 14・18）。

## 保証の主張

差分プライバシー付きの生成 M は、次を満たす。

> 被験者を1人だけ別の人に入れ替えた2つの学習データ D、D′（人数 n は同じ）と、合成データの任意の集合 S について、
> P[M(D) ∈ S] ≤ e^ε · P[M(D′) ∈ S] + δ

- 単位は被験者（バイタルでは滞在1件、心電図では1人の記録）
- 隣接関係は「1人の入れ替え」（bounded DP）。人数 n は公開とみなす
- δ = 10⁻⁵

## 根拠

### 1. 被験者ごとの寄与を、公開の定数で有界にする

学習データを読むのは、雑音を加える前の総和を計算する関数（`dpsynth.query_sums`、`ecgdefense.dp_sums`）だけにした。各被験者の寄与を、データを見ずに決めた範囲に切り詰めるので、1人を入れ替えたときの総和の変化（L2感度 Δ）に上界がある。

| 実装 | 総和 | 被験者ごとの寄与の範囲 | 感度 Δ |
|---|---|---|---|
| バイタル（`dpsynth`） | Σu_i | u_i ∈ [0, 1]⁸ | √8 ≈ 2.83 |
| | Σu_i u_iᵀ | 各成分 ∈ [0, 1] | 8 |
| | ΣC0_i、ΣC1_i | 各成分 ∈ [−1.01, 1.01] | 2 × 1.01 × 3 = 6.06（各） |
| 心電図（`ecgdefense`） | Σm_i | ‖m_i‖₂ ≤ 8 | 2 × 8 = 16 |
| | Σm_i m_iᵀ | ‖m_i m_iᵀ‖_F = ‖m_i‖₂² ≤ 64 | 2 × 64 = 128 |
| | ΣW_i（被験者内の残差の二次モーメント） | 残差 ‖r‖₂ ≤ 4 なので ‖W_i‖_F ≤ 16 | 2 × 16 = 32 |
| | 心拍間隔の平均・2乗・標準偏差の総和 | 0.3〜2.0秒、0〜0.5秒 | 1.7、3.91、0.5 |

感度は、2つの寄与の差のノルムの最大値（入れ替えなので「最大の寄与の2倍」か「範囲の幅」）として求めた。被験者内で標準化した系列のラグ0・ラグ1の共分散の各成分が |·| ≤ T/(T−1) ≈ 1.007 に収まるのは、コーシー・シュワルツの不等式による（144時点で、上界1.01で切り詰める）。

### 2. ガウス機構

L2感度 Δ の総和に、平均0・標準偏差 σ の正規分布の雑音を各成分に独立に加えると、ρ = Δ² / (2σ²) の zCDP を満たす（Bun & Steinke 2016 のガウス機構の結果）。

### 3. 合成定理

バイタルは4つ、心電図は6つの総和にそれぞれ雑音を加える。zCDP は加法的に合成でき（同論文の合成の結果）、全体で ρ = Σ_j ρ_j になる。実装では ρ を等分し、σ_j = Δ_j / √(2ρ/J)（J は総和の数）とした。

### 4. (ε, δ) への換算

ρ-zCDP は、任意の δ > 0 で (ρ + 2√(ρ log(1/δ)), δ)-DP を満たす（同論文の zCDP から (ε, δ)-DP への換算）。実装では、目標の ε から ρ = (√(log(1/δ) + ε) − √(log(1/δ)))² を求めた（`dpsynth.rho_from_eps`）。

### 5. 後処理

雑音を加えた総和から平均・共分散・VAR(1)の係数を推定し、正規分布から合成データを引き、値を公開の生理的な範囲で切り詰める処理は、学習データを読まない。DP は後処理で弱まらない（後処理の不変性）。合成データから計算するあらゆる量（論文の図表、学習したモデル）も、同じ保証を持つ。

## 実装での確かめ方

| 確かめたこと | 方法 | 結果 |
|---|---|---|
| 感度の上界が成り立つ | 被験者1人を、極端な値・一定の値・激しく揺れる値・範囲外の年齢の人（バイタル）、振幅の大きい拍・平らな拍・雑音だけの拍・心拍間隔の端の人（心電図）に入れ替え、総和の変化を測る（`tests/test_dp_sensitivity.py`） | すべて上界以下。最悪で上界の50〜95% |
| 雑音の大きさが会計と一致する | Σ Δ_j² / (2σ_j²) が ρ に、ρ + 2√(ρ log(1/δ)) が ε に一致するか | 一致 |
| 生成が総和以外のデータを読まない | 総和を固定値に差し替え、学習データを変えても生成結果が同じか | 同じ（バイタル・心電図とも） |
| 実装に大きな誤りがない | 外れた被験者を狙ったメンバーシップ推論で、εの下限を実測する（GHE issue 14） | ε = 0.5〜8 のどの条件でも、実測の下限（最大0.19）は理論値を超えなかった |

最後の監査は、使った攻撃が弱いので、保証が成り立つことの証明にはならない。実装の大きな誤り（雑音の入れ忘れ、感度の取り違え）を見つけるためのもの。

## 保証が及ばない範囲

| 前提 | 崩れる場合 | 今回の状況 | 対処 |
|---|---|---|---|
| 1人＝1単位 | 同じ人が複数の記録を持つと、その人への保証は弱まる。k件持つ人には ρ が k² 倍になる | eICU Demo の学習データ A（716滞在）は597人の患者で、75人が2回以上、最大5回入室している。滞在単位の ε = 4 は、5回入室した患者には ε = 26（ε = 1 なら 5.4）。MIT-BIH の201と202も同じ人 | 1人を1系列にそろえてから使う（最初の滞在だけにする、などを前処理で行う） |
| 人数 n は公開 | 「1人の追加・削除」に対する保証が要る場合、人数自体を雑音つきで出す必要がある | 入れ替えの保証のみ | 人数を公開してよいかを決める。だめなら人数にも雑音を加える |
| 公開の範囲はデータを見ずに決める | 範囲や切り詰めの定数をデータを見て決めると、その決め方から情報が漏れる | 範囲は成人の一般的な目安として決めたが、筆者はそれ以前にこのデータを見ている | 先生方のデータでは、データを見る前に範囲を決めて記録する |
| 公開は1回 | 同じデータから合成データを何度も出すと、εが足し合わされる | 評価のために、同じ学習データから ε・シードを変えて何十回も生成した（研究としての評価で、公開はしていない） | 公開するのは1回に限る。ε・設定をデータで選ぶなら、その選択も予算に含めるか、公開データで決める |
| 前処理は1人ごとに閉じる | 対象の選択や正規化を、他の人のデータを使って決めると、その段階で情報が混ざる | 前処理（R波の検出、拍の切り出し、補間）は1人ごとに閉じている。ただし「記録率80%以上の滞在だけを使う」選択は、人数 n を変えうる | 選択基準を本人のデータだけで決め、人数の扱いと合わせて記録する |
| 浮動小数点で正しく雑音を出す | 浮動小数点の丸めで、理論上の分布からずれた雑音の性質を突く攻撃がある（Mironov 2012） | numpy の正規乱数をそのまま使っている | 実際の公開では、検証された実装（OpenDP など）を使う |
| DP 版だけが対象 | DP 版以外の作り方（主成分の基底、分位点での切り詰め、外れた人の除外を使う作り方）には保証がない | 見本用データの既定（`showcase-release`）と、心電図の E1〜E3・対策つきの版は DP ではない | 「DP の保証がある」と書くのは `dpsynth.generate_dp` と `E2-dp` だけにする |

ε の大きさにも注意が要る。ε = 8 では、1人の有無で出力の確率が最大 e⁸ ≈ 3,000倍変わりうる。NIST SP 800-226 は、ε が1を超える場合は公開物のリスクを別に評価するよう勧めている。今回、ε = 8 でも攻撃は当て推量並みだったが、それは使った攻撃に対する結果で、保証が強いという意味ではない。

## データの特徴ごとの難しさ

| データの特徴 | 保証を付けるときの難しさ | このリポジトリでの扱い | 残る課題 |
|---|---|---|---|
| 1人が多数の記録を持つ（時系列・拍） | 記録単位の保証では、1人の情報は記録の数だけ漏れる。人単位の保証には、1人の記録全体の寄与を有界にする必要がある | 1人の系列・拍をまとめた統計量（平均・共分散）だけを使い、1人の寄与を1つのベクトル・行列にした | 同じ人の複数の滞在・記録（上の表） |
| 値に上限がない、裾が重い | 感度が無限になるので、切り詰めの範囲を決める必要がある。広くすると雑音が大きく、狭くすると切り詰めで歪む | 生理的な範囲・成人の目安で決めた | 範囲をデータを見ずに決める手続き |
| 時間の依存（自己相関） | 依存の構造を表す統計量を足すたびに、予算を分ける必要がある | VAR(1)のラグ0・ラグ1の共分散（3×3）だけにした | より長い依存、非線形の変化、心拍変動は表せない |
| 多数のチャネル・高い次元 | 統計量の数が次元の2乗で増え、1つあたりの予算が減る | バイタルは3変数、心電図は DCT の20係数に絞った | 12誘導の心電図などでは、統計量の数が増えて雑音が大きくなる |
| データから作る前処理（主成分の基底、正規化） | 前処理自体がデータを読むので、DP にするか、データに依存しない方法に代える必要がある | 心電図は主成分の代わりに DCT の基底を使った | DCT は主成分より拍の形の再現が粗い（判別スコアが0.23から0.35〜0.40に悪化） |
| 被験者が少ない（数十人） | 雑音の大きさは人数によらず、推定する平均・共分散のずれは 1/n で大きくなる | 716人なら ε = 4〜8 で見本として使えたが、20〜50人では ε = 8 でも使えなかった | 他の研究のデータと合わせて人数を増やす、統計量を減らす |
| 生体認証に使える信号（心電図） | 外れた波形の人は、少しの情報でも識別されうる。ε が大きいと外れた人は守られない（NIST SP 800-226） | 心電図の E2-dp では、照合攻撃は当て推量並み（AUC 0.48〜0.52）だった | 強い識別器での照合、大きな ε での外れた人の評価 |

## 先生方のデータで保証を主張するなら

1. データを見る前に、単位（1人＝1単位）、公開の範囲、ε・δ、使う統計量を決めて記録する
2. 1人の複数の記録を、1つの単位にまとめる前処理を入れる
3. 合成データの公開は1回にする。設定の選択は公開データで行う
4. 雑音の生成には、検証された実装を使う
5. 感度のテストと、攻撃による監査（実測の下限が理論値を超えないこと）を行い、記録する
6. 公開物には、ε・δ・単位・隣接関係・会計の方法を書く
