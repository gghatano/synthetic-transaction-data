# Banksformer本体の再学習

issue #6の成果物。#2の追試（[replication-banksformer.md](replication-banksformer.md)）ではBanksformer（BF）を実行せず論文値を転記していた。
著者コードを実行し、他のモデルと同じデータ・同じ指標で評価した。

## 要点

1. **論文の主要な主張は再現した。** 月内日の分布（DoM 0.016、論文0.011）とtcode 3-gram（0.091、論文0.042）で、BFは #2で比べたどのモデルよりも良い。3-gramはtcodeをシャッフルした基準（0.186）を大きく下回り、取引コードの順序を学習している。金額（Amt 2,033、論文2,102）もほぼ一致した。
2. **時間構造の指標でもBFが最良。** 取引間隔（TD 1.18）はCTGAN（18.3）・PAR（2.5）・DGAN（2.4）より良い。月あたり取引件数（1.41）はPAR（0.36）に次ぐ。(Tcode, DoM) は0.048で、月末の利息計上のような日付と取引種別の結びつきを学習している。
3. **論文値と合わない指標が2つある。** CF（4,553 vs 2,738）と (Tcode, DoM)（0.048 vs 0.251）。(Tcode, DoM) は今回のほうがかなり良い。著者の評価コードでは、(tcode, 日付) の同時分布を計算する行でtcodeではなくループ変数`code`（ループ終了時は`type`）を渡しており、論文の値は (type, 日付) で計算されている可能性がある（未検証）。
4. **CPUのみで実行できる。** 学習50エポック（early stopping）で68分、5,000系列の生成で約25分（他の学習と並行実行での値）。

## 方法

- 著者リポジトリ（https://github.com/BigTuna08/Banksformer_ecml_2022、コミット`4e99894`）にはLICENSEがないため、本リポジトリには取り込まない。`external/banksformer/run.py`が実行時に`data/banksformer_src`へcloneし、ノートブック3本（前処理・エンコード・学習と生成）をheadlessで実行する
- 実行環境は別のuvプロジェクト（`external/banksformer/`、Python 3.10、TensorFlow 2.15 CPU版、pandas 1.5）
- 学習データは他のモデルと揃えて学習用Aの口座（7,259系列）に限定した。論文は全口座で学習している
- ノートブックへの変更は設定値の置換だけ: 乱数シードの固定、学習するモデル数（著者は同じ設定で3モデル、今回は1モデル）
- ハイパーパラメータは著者コードのまま（d_model 128、デコーダ4層、ヘッド2、最大80エポック、early stopping 2）。生成は著者コードと同じく、開始日と年齢を実データから復元抽出し、長さ80の系列を5,000本

実行手順は次のとおり。

```bash
cd external/banksformer
uv sync
uv run python run.py --root ../.. --seed 0
cd ../..
uv run transyn evaluate
```

## 結果

BFはシード0の1回。他のモデルとの比較で挙げた数値は #2のシード0の値。

| | Amt | CF | Tcode | DoM | Tcode3G | TcodeDoM | TD | TxPerMonth |
|:--|--:|--:|--:|--:|--:|--:|--:|--:|
| Real-B（実データ同士） | 75 | 144 | 0.000 | 0.000 | 0.006 | 0.002 | 0.04 | 0.05 |
| Real-B tcodeシャッフル | 75 | 10,817 | 0.000 | 0.000 | 0.186 | 0.211 | 0.04 | 0.05 |
| Real-B日付シャッフル | 75 | 2,328 | 0.000 | 0.000 | 0.169 | 0.211 | 21.37 | 3.66 |
| banksformer | 2,033 | 4,553 | 0.024 | 0.016 | 0.091 | 0.048 | 1.18 | 1.41 |
| 論文BF | 2,102 | 2,738 | 0.004 | 0.011 | 0.042 | 0.251 | – | – |

生成データの基本統計: 系列長80、同日取引の割合0.238（実データ0.230）、金額の平均5,228（実データ5,940）。

## 結論

- 著者コードをCPU環境で再実行し、論文のTable 2のうちAmt・DoM・3-gramの主張（BFは日付パターンと取引順序を他手法より良く再現する）を再現した。
- #2で追加した時間構造の指標（TD・TxPerMonth）でもBFは良好で、行独立のCTGANとの差がはっきり出る。
