# Banksformer 本体の再学習

issue #6 の成果物。#2 の追試（[replication-banksformer.md](replication-banksformer.md)）では Banksformer（BF）を実行せず論文値を転記していた。
著者コードを実行し、他のモデルと同じデータ・同じ指標で評価した。

## 要点

1. **論文の主要な主張は再現した。** 月内日の分布（DoM 0.016、論文 0.011）と tcode 3-gram（0.091、論文 0.042）で、BF は #2 で比べたどのモデルよりも良い。3-gram は tcode をシャッフルした基準（0.186）を大きく下回り、取引コードの順序を学習している。金額（Amt 2,033、論文 2,102）もほぼ一致した。
2. **時間構造の指標でも BF が最良。** 取引間隔（TD 1.18）は CTGAN（18.3）・PAR（2.5）・DGAN（2.4）より良い。月あたり取引件数（1.41）は PAR（0.36）に次ぐ。(Tcode, DoM) は 0.048 で、月末の利息計上のような日付と取引種別の結びつきを学習している。
3. **論文値と合わない指標が 2 つある。** CF（4,553 vs 2,738）と (Tcode, DoM)（0.048 vs 0.251）。(Tcode, DoM) は今回のほうがかなり良い。著者の評価コードでは、(tcode, 日付) の同時分布を計算する行で tcode ではなくループ変数 `code`（ループ終了時は `type`）を渡しており、論文の値は (type, 日付) で計算されている可能性がある（未検証）。
4. **CPU のみで実行できる。** 学習 50 エポック（early stopping）で 68 分、5,000 系列の生成で約 25 分（他の学習と並行実行での値）。

## 方法

- 著者リポジトリ（https://github.com/BigTuna08/Banksformer_ecml_2022 、コミット `4e99894`）には LICENSE がないため、本リポジトリには取り込まない。`external/banksformer/run.py` が実行時に `data/banksformer_src` へ clone し、ノートブック 3 本（前処理・エンコード・学習と生成）を headless で実行する
- 実行環境は別の uv プロジェクト（`external/banksformer/`、Python 3.10、TensorFlow 2.15 CPU 版、pandas 1.5）
- 学習データは他のモデルと揃えて学習用 A の口座（7,259 系列）に限定した。論文は全口座で学習している
- ノートブックへの変更は設定値の置換だけ: 乱数シードの固定、学習するモデル数（著者は同じ設定で 3 モデル、今回は 1 モデル）
- ハイパーパラメータは著者コードのまま（d_model 128、デコーダ 4 層、ヘッド 2、最大 80 エポック、early stopping 2）。生成は著者コードと同じく、開始日と年齢を実データから復元抽出し、長さ 80 の系列を 5,000 本

実行:

```bash
cd external/banksformer
uv sync
uv run python run.py --root ../.. --seed 0
cd ../..
uv run transyn evaluate
```

## 結果

BF はシード 0 の 1 回。他のモデルとの比較で挙げた数値は #2 のシード 0 の値。

| | Amt | CF | Tcode | DoM | Tcode3G | TcodeDoM | TD | TxPerMonth |
|:--|--:|--:|--:|--:|--:|--:|--:|--:|
| Real-B（実データ同士） | 75 | 144 | 0.000 | 0.000 | 0.006 | 0.002 | 0.04 | 0.05 |
| Real-B tcode シャッフル | 75 | 10,817 | 0.000 | 0.000 | 0.186 | 0.211 | 0.04 | 0.05 |
| Real-B 日付シャッフル | 75 | 2,328 | 0.000 | 0.000 | 0.169 | 0.211 | 21.37 | 3.66 |

| 論文 BF | 2,102 | 2,738 | 0.004 | 0.011 | 0.042 | 0.251 | – | – |

生成データの基本統計: 系列長 80、同日取引の割合 0.238（実データ 0.230）、金額の平均 5,228（実データ 5,940）。

## 結論

- 著者コードを CPU 環境で再実行し、論文の Table 2 のうち Amt・DoM・3-gram の主張（BF は日付パターンと取引順序を他手法より良く再現する）を再現した。
- #2 で追加した時間構造の指標（TD・TxPerMonth）でも BF は良好で、行独立の CTGAN との差がはっきり出る。
