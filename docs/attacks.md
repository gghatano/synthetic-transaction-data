# 見本用データへのプライバシ攻撃

GHE issue 13の成果物。見本用データの公開前チェック（GHE issue 9、[showcase-levels.md](showcase-levels.md)）は、最近傍距離・完全一致・極値で開示リスクを測っていた。最近傍距離などの類似度による指標は、少数派や外れた記録の漏れを見逃すことが知られている（Ganev, De Cristofaro, IEEE S&P 2025; Stadler et al., USENIX Security 2022）。攻撃者が実際にやりそうな攻撃を試し、どの段階・人数で何が漏れるかを先回りして確かめた。

## 要点

1. **L3・L4では、外れた被験者が学習に入っていたかを当てられた。** 標的を学習データに入れた生成と入れない生成を200回ずつ繰り返して当てさせると、外れた被験者5人を狙ったAUCは20人の学習でL3が0.79・L4が0.82、経験的なεの下限（真陽性率と偽陽性率の比の対数）は約2.2だった。学習人数が増えると下がるが、200人でもAUC 0.59〜0.62で、10人中8人の標的でεの下限が正だった。
2. **平均的な被験者は、どの段階でも当て推量並みだった。** AUCは0.48〜0.54。漏れは外れた被験者に集中しており、平均で測る指標では見えない。距離に基づくメンバーシップ推論（GHE issue 9）のAUCがどの段階でも0.48〜0.50だったのはこのため。
3. **L1・L2は、外れた被験者でも漏れなかった。** AUCは0.47〜0.56、εの下限はほぼ0（20人の学習のL2で5人中1人だけ0.05）。L1は値を時点・被験者と独立に引き、L2は全員共通の平均・ばらつきしか使わないので、1人の特徴が合成データに現れない。
4. **分位点での切り詰めは、この漏れを防がない。** 切り詰めは実在の被験者の極値を消すが、外れた被験者の「被験者ごとの平均・ばらつき」という特徴は、L3・L4が引く多変量正規分布の推定に残る。
5. **属性推論と部分系列による所属推定では、はっきりした漏れは見えなかった。** 年齢と前半1時間から死亡退院を推測させると、716人の学習では学習した人のほうが当たりにくかった（差−0.02〜−0.07）。50人の学習のL4では学習した人で0.13高かったが、3シードの標準偏差が0.11と大きい。1時間分の系列から最も近い区間を探す攻撃は、どの段階でもAUC 0.47〜0.50だった。

## 方法

- データ: eICU Demo v2.0.1の定期バイタル（公開リポジトリの#15と同じ前処理）
- 生成: 見本用データの段階 L1〜L4（GHE issue 9）。公開の既定どおり、値を学習データの0.5〜99.5パーセンタイルで切り詰める。生成数は狙い撃ちでは200人、それ以外は716人

### 攻撃

| 攻撃 | 攻撃者が知っていること | 手順 | 成功の指標 |
|---|---|---|---|
| 狙い撃ちのメンバーシップ推論 | 標的の被験者の記録すべてと、母集団の他の人の記録 | A・Bの1,070人から、標的以外を n−1 人（標的を入れる試行）または n 人（入れない試行）抜いて生成する。標的の被験者ごとの平均・log標準偏差（6次元）に最も近い合成の被験者までの距離で、入っていたかを当てる。標的ごとに200回（半分ずつ） | AUC、経験的なεの下限 |
| 属性推論 | 学習データに含まれうる人の年齢と前半1時間のバイタル | 合成データで学習したロジスティック回帰で死亡退院を推測し、学習した人（A）と学習していない人（B）でAUROCを比べる | AUROCの差（学習した人 − していない人） |
| 部分系列による所属推定 | 実在の被験者の1時間分（12点）の系列 | 合成データの中で最も近い1時間の区間までの距離で、学習データに入っていたかを当てる。学習した人・していない人それぞれ200人 | AUC |

標的は、A・Bの1,070人のうち、被験者ごとの特徴量の標準化距離が小さい5人（平均的な被験者）と大きい5人（外れた被験者）。

経験的なεの下限は、しきい値ごとに真陽性率の信頼下限と偽陽性率の信頼上限（クロッパー・ピアソン、95%）の比の対数をとった最大値。しきい値を同じ試行から選ぶので厳密な下限ではなく目安。差分プライバシーの監査の研究（Jagielski et al. 2020; Nasr et al. 2021, 2023）と同じ考え方で、GHE issue 14の監査にも使う。

実行手順は次のとおり。

```bash
uv run transyn vitals-prepare
for n in 20 50 200; do uv run transyn attacks-targeted --n $n --reps 200; done
uv run transyn attacks-population
```

所要時間（CPU、4本並行）は、狙い撃ちが1本約1時間（大半はL4の生成）、属性推論と部分系列が約20分。

### 読み取り

- 外れた被験者の漏れは、L3・L4が被験者ごとの平均・ばらつきの分布（多変量正規分布）を学習データから推定することから来る。外れた1人がいると平均と共分散がその人の方向に引っ張られ、合成の被験者がその人の近くに出やすくなる。人数が少ないほど1人の影響が大きく、20人の学習で最も強く漏れた。
- 外れた被験者の中でもAUCは幅があり、20人の学習では0.69〜0.98だった。最も外れた標的ほど当てられやすいわけではなく、20人・50人の学習では外れ具合とAUCの順位相関が−0.6〜−0.8と逆向きだった。20人の学習では、外れ具合（標準化距離）が8.4〜8.6の2人のAUCが0.90〜0.97、15.0前後の3人が0.71〜0.75。極端に外れた人は多変量正規分布の裾の外にいて、合成の被験者がその人の近くまで出にくいためと考えられる。外れ具合の大きさだけで危ない人を選ぶと見落とす。
- L3とL4の差は小さく、死亡退院との関係を加えること（L4）による上乗せは0.03程度だった。
- 50人の学習のL4での属性推論の差（0.127）は、学習した50人のうち死亡退院が数人しかいないため、AUROC自体のばらつきが大きい。L4は死亡退院の有無で群を分けて推定するので、少人数の群の被験者の特徴が合成データに強く残る（GHE issue 3で見た「少人数の群」の問題）可能性があり、追加の確認が要る。
- 部分系列による所属推定が効かなかったのは、どの段階も系列そのものを学習データから写さないため。

## 公開前チェックへの示唆

- 公開前チェックに、外れた被験者を標的にした狙い撃ちのメンバーシップ推論を加える。距離に基づく平均的な指標だけでは、外れた被験者の漏れが見えない。
- 数十人のデータでL3・L4（被験者ごとの違いを保つ段階）を公開するなら、外れた被験者への対策が要る。候補は、外れた被験者を除いてから推定すること、差分プライバシーを入れること（GHE issue 14）。
- L2（被験者内の時間変化まで）までなら、試した攻撃に対しては漏れなかった。ただし、試していない攻撃に対しては何も言えない。

## 制約

- 狙い撃ちの攻撃の手がかりは、被験者ごとの平均・log標準偏差の最近傍距離だけ。尤度比や密度推定を使う、より強い攻撃（Stadler et al.のシャドーモデルの分類器、DOMIAS など）を使えば、漏れはさらに大きく見える可能性がある
- 攻撃者は標的の記録すべてと母集団の他の人の記録を知っているという、強い仮定を置いた。実際の攻撃者はここまで知らないことが多いが、最悪の場合の目安になる
- 標的は外れた被験者・平均的な被験者の5人ずつ。経験的なεの下限は、しきい値を同じ試行から選んだ目安
- 心電図による個人識別（生体認証）の攻撃は、多誘導の心電図データが要るので試していない
