# 合成データで水増しして検定すると何が起きるか

GHE issue 1の成果物。「合成データで被験者を増やせば、少ない実験者数で検定できるのではないか」という問いに答えるため、合成データを実データとみなした検定の第1種の過誤率を測った。

前段として、Decruyenaere et al.（*The Real Deal Behind the Artificial Appeal: Inferential Utility of Tabular Synthetic Data*, UAI 2024）の表データでのシミュレーションを追試し、次に同じことが被験者ごとの時系列（eICU Demoのバイタル）でも起きるかを確かめた。

## 要点

1. **表データでの先行研究の主張を再現した。** 合成データ（M = n）を実データとみなして検定すると、統計モデルの合成でも第1種の過誤率は12〜19%になる。標準誤差に √(1 + M/n) を掛ける補正で、統計モデルは2〜6%に戻るが、CTGAN・TVAEは補正しても5.5〜94%のままだった（推定できた試行が9回しかないTVAEのn=50の治療の係数を除く）。著者の図（年齢の平均で既定のCTGANが50〜92%、既定のTVAEが45〜76%）と同じ水準。
2. **被験者ごとの時系列でも同じことが起きた。** 群間差のない2群を作り、群ラベルを条件にして生成モデルを学習した。VAR(1)の合成データでは、素朴な検定の偽陽性はM = nで14〜18%、M = 5nで35〜45%で、補正すると3.5〜8%に戻った。PARでは素朴な検定で38%、補正しても24%、DGANでは素朴な検定で79%、補正しても71%だった。
3. **深層モデルで補正が効かない原因は、被験者ごとの違いの縮みと、生成の不安定さだった。** PARの合成データでは、被験者ごとの平均心拍数のばらつきが実データの0.48倍しかなく（VAR(1)は1.01倍）、標準誤差が小さく出た。DGANでは縮みは0.83倍と小さかったが、合成データでの群間差が試行ごとに大きくぶれた（標準偏差19.3 bpm、実データでは4.2 bpm）。素朴な標準誤差は、合成データでの群間差の試行間のばらつきの0.34倍（PAR）と0.12倍（DGAN）しかなかった。公開リポジトリの#15で見た「深層モデルは患者ごとの違いを再現できない」ことと、#5・#17で見た「DGANはシードによって崩れる」ことが、推論の誤りとして現れた。
4. **記録を独立とみなす検定は、合成以前に誤る。** 実データでも、5分ごとの記録を1件ずつ独立な観測として2群を比べると、真の差がないのに83〜88%で有意になった。被験者単位で比べれば4〜7%。トランザクション型のデータでは、独立な単位は被験者で、記録の件数ではない。
5. **合成データで人数を増やすことは、検定の情報を増やさない。** 補正つきの検定が妥当になるのは、合成データの推定量の分散を σ²(1/n + 1/M) とみなせる場合だけで、M をいくら増やしても分散は σ²/n を下回らない。必要な実験者数を減らすには外部の情報が要る（GHE issue 2、[prognostic-covariate.md](prognostic-covariate.md)）。

## 前段: 表データでの追試

### 方法

著者コード（https://github.com/syndara-lab/inferential-utility 、MITライセンス）の`utils/disease.py`と同じ生成過程で実データを作る。

- 年齢 ~ 正規(50, 10²)
- 病期（I〜IV）: 年齢を説明変数にした比例オッズモデル（切片2・3・4、係数−0.05）
- バイオマーカー: 病期ごとのガンマ分布（形状25、平均 1/(4 + β_病期)）
- 治療: ベルヌーイ(0.5)
- 死亡: ロジスティック（切片−3、年齢0.05、病期0・0.5・1・1.5、治療−0.5）

n人（50・160・500・1600・5000）の実データから生成モデルを学習し、同じ人数（M = n）の合成データを作る。母集団の真値（年齢の平均50、死亡に対する治療の係数−0.5）を帰無仮説にした検定（著者と同じく、平均はt分布、回帰係数は標準正規）で棄却した割合を第1種の過誤率とした。各条件200回（CTGANのn=1600のみ100回）。

| 生成モデル | 内容 | 著者との違い |
|---|---|---|
| parametric | 生成過程と同じ構造（正規・比例オッズ・病期ごとのガンマ・ベルヌーイ・ロジスティック）をデータから推定し、その順に生成 | 著者の統計モデルはsynthpop（R）とベイジアンネットワーク。正しく特定されたモデルとして代えた |
| ctgan | SDV 1.38.5の`CTGANSynthesizer`、既定のハイパーパラメータ（300エポック） | 著者は既定版と調整版の両方。こちらは既定版のみ。実装はsynthcityではなくSDV |
| tvae | SDVの`TVAESynthesizer`、既定 | 同上 |

依存を増やさないため、ロジスティック回帰と比例オッズモデルはnumpy・scipyで実装した。推定量は年齢の平均と治療の係数の2つに絞った（著者は17個）。n=5000はparametricのみ。

## 本題: 被験者ごとの時系列

### 方法

- データ: eICU Demo v2.0.1の定期バイタル（公開リポジトリの#15と同じ前処理）。心拍数・SpO2・呼吸数を5分刻みにした入室から12時間（144点）の系列、A/B/Cを合わせた1,422滞在
- 1回の試行:
  1. 1,422滞在から n 人を抜き、ランダムに半分ずつ2群のラベルを付ける（真の群間差は0）
  2. 群ラベルを条件にして生成モデルを学習し、M 人分を生成する。群ラベルは、#15の生成モデルが条件に使っている死亡退院の列に入れた
  3. 被験者ごとの平均心拍数を2群で比べる（Studentのt検定）。合成データでは素朴な検定と、標準誤差に √(1 + M/n) を掛けた補正つきの検定
  4. 実データでも、被験者単位の検定と、5分ごとの記録を独立とみなした検定を行う
- 生成モデルは#15と同じ実装

| 生成モデル | 設定 | n, M | 試行数 |
|---|---|---|---|
| var1 | 滞在ごとの性質を群ごとの多変量正規、滞在内をVAR(1) | n = 20・50・100・200、M = n と 5n | M = nは500回、M = 5nは200回（n=20のみ284回） |
| par | SDV PAR、200エポック | n = 100、M = 100 | 100回 |
| dgan | gretel版DGAN、バッチ64、3,000エポック（更新6,000回） | n = 100、M = 100 | 48回 |

DGANの更新回数は#15（24,000回）より少ない。1回の試行の学習に約6.5分かかるため、試行回数とのかね合いで減らした。

### 読み取り

- 素朴なSE ÷ 実際のばらつきは、VAR(1)ではM = nで約0.71、M = 5nで約0.41になった。理論上の比 1/√(1 + M/n) はそれぞれ0.71と0.41で、ちょうど一致する。統計モデルでは、合成データの推定量の分散が σ²(1/n + 1/M) とみなせ、補正が効く。
- M = 5n で補正後も7.5〜8%と少し高い条件がある（n=50・100）。VAR(1)は群ごとの平均・共分散を少人数から推定するので、推定のぶれが補正の想定よりやや大きい可能性がある。
- PARでは、被験者ごとの平均のばらつきが実データの0.48倍（試行ごとに0.11〜1.13倍）に縮み、素朴な標準誤差は実データの約半分（1.60 vs 3.51）になった。一方で、合成データでの群間差は試行ごとに実データより大きくばらついた（標準偏差4.73 vs 3.66）。合成データでの群間差と実データでの群間差の相関は0.35で、生成モデルの学習のぶれが大きい。
- DGANでは、被験者ごとの平均のばらつきの縮みは平均0.83倍（試行ごとに0.33〜1.71倍）とPARより小さかったが、合成データでの群間差が試行ごとに−47〜+60 bpmと大きくぶれた（標準偏差19.3 bpm、実データでは4.2 bpm）。群ラベルを属性として条件付けた生成が試行ごとに異なる方向に崩れ、存在しない大きな群間差を作っている。補正が効かない主因は縮みよりこの不安定さで、公開リポジトリの#5・#17で見た「DGANはシードによって崩れる」ことと同じ性質。DGANの実データでの被験者単位の過誤率0.104は、PARと同じ最初の48試行の値で、100試行では0.070（標準誤差はそれぞれ0.044と0.026）。
- 記録単位の検定は、5分ごとの144点を独立とみなすので、標準誤差が被験者内の相関の分だけ過小になる。合成以前の、トランザクション型データに特有の誤り。

## データ共有と実験への示唆

- 合成データを学外に渡す場合、受け取った側がそれを実データとみなして検定すると、偽陽性が大幅に増える。見本用データには「推論には使えない」ことを明記する必要がある。
- 深層生成モデルの合成データでは、補正つきの検定も信用できない。統計モデルの合成データでも、補正つきの検定が妥当になるのは、生成モデルが正しく特定されている場合に限る。
- 合成データで被験者を増やしても、検定の情報は実データの n 人分を超えない。必要な実験者数を減らしたいなら、外部データの予後予測を共変量にする方法などを使う（[prognostic-covariate.md](prognostic-covariate.md)）。
- 分析では、独立な単位が被験者であることを守る。記録単位で検定すると、合成データを使わなくても誤る。

## 制約

- 表データの追試は、著者の17個の推定量のうち2個、10個の生成モデルのうち相当するもの3個（統計モデルはsynthpopではなく自前のパラメトリックモデル）。CTGAN・TVAEはSDVの既定設定で、著者の調整版は試していない
- 時系列の深層モデル（PAR・DGAN）は n = 100 の1条件のみ
- 群間差の検定は平均心拍数の1つの量だけ。自己相関やスペクトルのような系列の性質の検定は試していない
- 群ラベルはランダムで、生成モデルは群間差がないことを知らない。実際の共有データでは群間差がある場合も多く、その場合の推定の偏りは測っていない

## 再現手順

```bash
uv run transyn vitals-prepare
# 表データの追試
for n in 50 160 500 1600; do
  for m in parametric ctgan tvae; do uv run transyn syninf-tab-run $m --n $n --reps 200; done
done
uv run transyn syninf-tab-run parametric --n 5000 --reps 200
uv run transyn syninf-tab-summary
# 時系列
for n in 20 50 100 200; do
  uv run transyn syninf-run var1 --n $n --m $n --reps 500 --epochs 0
  uv run transyn syninf-run var1 --n $n --m $((5*n)) --reps 200 --epochs 0
done
uv run transyn syninf-run par --n 100 --m 100 --reps 100 --epochs 200
uv run transyn syninf-run dgan --n 100 --m 100 --reps 48 --epochs 3000
uv run transyn syninf-summary
```

`--start`でシードの開始番号を変えると別のファイルに書き出すので、並行に実行できる。所要時間（CPU、他の実験と並行）は、表データのCTGANで1回5〜60秒、時系列のVAR(1)で1回1〜5秒、PARで約2分（並行時は約10分）、DGANで約6.5分。
