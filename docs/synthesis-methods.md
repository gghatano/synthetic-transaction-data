# 合成データの作り方

GHE issue 22の成果物。各レポートの方法の節に分散していた合成データの作り方を、1つにまとめた。どの作り方も「学習データ（実データ）→ 合成データ」を返す関数として実装していて、実装の場所を各節に示す。

## 1. 全体像

| 系統 | 作り方 | 主な対象 | 実装 |
|---|---|---|---|
| 行を独立に作る表形式の生成 | CTGAN、TVAE | 取引、EHR、バイタル、表データ | SDV（`models.fit_generate_ctgan` など） |
| 系列の深層モデル | PAR、DGAN、Banksformer、GPT型 | 取引、EHR、バイタル | SDV、gretel-synthetics、著者コード、`seqgpt` |
| 統計モデル | VAR(1)（被験者ごとの性質＋被験者内の変動） | バイタル | `vitals.fit_generate_var1` |
| 見本用データの段階 | L0〜L4 | バイタル | `showcase.generate` |
| 差分プライバシー版 | L3・L4のDP版、心電図のE2のDP版 | バイタル、心電図 | `dpsynth.generate_dp`、`ecgdefense.generate("E2-dp")` |
| 心電図の拍の合成 | E0（力学系モデル）〜E3、対策つきの版 | 心電図 | `ecglink.generate`、`ecgdefense.generate` |
| 表データの逐次モデル | 生成過程と同じ構造の正規・比例オッズ・ガンマ・ロジスティック | 表データの追試 | `syninf_tabular.fit_generate_parametric` |

どの作り方にも共通する考え方として、**被験者（口座・滞在・人）を単位にする**。系列の深層モデルと統計モデルは、被験者ごとの性質（年齢や死亡退院などの属性、平均の水準、ばらつき）と、被験者内の時間の変化を分けて扱う。行を独立に作る生成だけは、この区別を持たない。

## 2. 行を独立に作る表形式の生成（CTGAN、TVAE）

- 1行＝1件の記録（取引、イベント、5分ごとのバイタルの1時点）として、SDVの `CTGANSynthesizer`・`TVAESynthesizer` で学習する
- 生成した行を、学習データの系列長の分布に従って束ね、1つの系列とみなす。バイタルでは、時刻番号ごとに条件付きで生成した行をランダムに束ねる
- 系列単位の属性は、束ねた先頭の行の値にそろえる
- SDVのCTGANは既定の `log_frequency=True` だとカテゴリの分布が平らになるので、`False` にする（公開リポジトリの#2）

行と行の関係を学習しないので、取引間隔、被験者内の自己相関、被験者ごとの違いは、構造上再現できない。

## 3. 系列の深層モデル

| 作り方 | 仕組み | このリポジトリでの使い方 |
|---|---|---|
| PAR（SDV） | 系列単位のコンテキスト（年齢・死亡退院など）を条件に、次の行を確率的に予測する自己回帰モデル | 系列キーと順序の列を与える。50〜200エポック |
| DGAN（DoppelGANger、gretel-synthetics） | 属性（系列ごとの値）と特徴量（時点ごとの値）を分けて生成するGAN | 取引では開始日を属性、取引間隔（log1p）を特徴量にする。バッチ64で更新を約2万回以上にする（バッチが系列数より大きいと更新が足りない、公開リポジトリの#17） |
| Banksformer | 取引の種類・金額・日付を順に生成する Transformer。日付に専用の仕組みを持つ | 著者コード（TensorFlow）を別環境で実行（`external/banksformer/`） |
| GPT型（`seqgpt`） | `<bos> 属性 [コード 間隔]... <eos>` をトークン列にして学習する小さなGPT（3層、d_model 128） | EHRのイベント系列。間隔はlogスケールの区間に離散化し、生成時に区間内で一様に戻す |

## 4. 統計モデル VAR(1)（`vitals.fit_generate_var1`）

被験者ごとの性質と、被験者内の変動を分けて作る。学習データの系列そのものは保持しない。

1. 被験者 i の系列 x_i（144時点 × 3変数）から、各変数の平均 m_i と標準偏差 s_i を求める
2. 被験者ごとの性質 v_i = (m_i, log s_i, 年齢) を、死亡退院の有無 d ごとに多変量正規分布 N(μ_d, Σ_d) で表す。群の人数が次元（7）以下なら、群の平均を引いた残差でまとめた共分散を使う（GHE issue 3）
3. 被験者内で標準化した変動 z_t = (x_t − m_i) / s_i に、変数間のVAR(1) を最小二乗で当てる: z_t = z_{t−1} A + e_t、e_t ~ N(0, Σ_e)
4. 生成: 死亡退院 d を学習データの割合で引き、v ~ N(μ_d, Σ_d) から平均・標準偏差・年齢を引く。z_0 ~ N(0, I) から VAR(1) で z_t を作り、x_t = m + s ⊙ z_t とする
5. 値を学習データの最小・最大で切り詰め、年齢を整数にする

被験者ごとの違い（v の分布）と、時間の変化（A と Σ_e）を、少数の統計量だけで表す。統計量が少ないので、少人数でも推定でき（GHE issue 3）、差分プライバシーも入れやすい（7節）。

## 5. 見本用データの段階（`showcase.generate`）

英国統計局（ONS）の合成データの段階を、被験者ごとの時系列に当てはめた5段階（GHE issue 9）。段階を上げるごとに、保つ性質を1つずつ加える。

| 段階 | 作り方 | 学習データから使うもの |
|---|---|---|
| L0 | 成人の一般的な参考範囲（心拍数50〜120、SpO2 88〜100、呼吸数10〜30、年齢18〜90、死亡退院10%）から、時点ごとに一様に引く | なし |
| L1 | 変数ごとに、学習データの全時点の値から時点ごとに独立に復元抽出する。年齢・死亡退院も独立に引く | 変数ごとの値の分布 |
| L2 | 4節の手順3と同じVAR(1)で z_t を作り、全員共通の平均・標準偏差に載せる: x_t = μ + σ ⊙ z_t（μ・σは全時点の平均と標準偏差） | 全体の平均・標準偏差、VAR(1) |
| L3 | 被験者ごとの (m, log s) を、属性と無関係な1つの多変量正規分布から引き、L2の変動を載せる | ＋被験者ごとの性質の分布 |
| L4 | 4節のVAR(1)そのもの（死亡退院ごとの分布、年齢を含む） | ＋属性との関係 |

公開用の既定（`showcase-release`）では、次の2つを加える。

- 値を学習データの最小・最大ではなく、0.5〜99.5パーセンタイルで切り詰める（実在の被験者の極値を出さない、GHE issue 9）
- L3・L4で、外れ具合（被験者ごとの性質の標準化距離）が上位の被験者を除いてから推定する選択肢（`trim`、GHE issue 14）

どちらも学習データから決めるので、差分プライバシーの保証はない。

## 6. 心電図の拍の合成（`ecglink.generate`）

心電図は拍の単位で作る。R波を検出し、R波の前0.25秒〜後0.45秒を0.5〜40 Hzに絞って128点に揃え、窓の中央値を引いたものを1拍とする。拍を主成分（20個）に分解し、その係数の空間で作る。

| 作り方 | 拍の形の平均 | 拍ごとのゆらぎ | 心拍間隔 |
|---|---|---|---|
| E0 | 心電図の力学系モデル（ECGSYN、McSharry et al. 2003）の3変数の常微分方程式を、論文の既定のパラメータで解く。P・Q・R・S・T波の振幅を±10%ゆらす | 方程式の解 | 心拍数 N(70, 8²) |
| E1 | 全員が集団の平均 | 被験者内の共分散（全員でまとめたもの） | 集団の平均と被験者内の標準偏差 |
| E2 | 被験者ごとに、被験者ごとの平均の分布 N(集団の平均, 被験者間の共分散) から引く。共分散は収縮推定（Ledoit-Wolf） | 同上 | 被験者ごとの平均を集団の分布から引く |
| E3 | 本人の平均 | 本人の共分散と集団の共分散を半々に混ぜたもの | 本人の平均 |

E0がデータから使うのは、拍の振幅の大きさ（集団の中央値）だけ。E3は本人ごとに作る個人の再現型で、ほぼ本人に結びつく（GHE issue 17）。

### 対策つきの作り方（`ecgdefense.generate`）

| 作り方 | 中身 |
|---|---|
| E3-kanon | E3で、本人の平均の波形の代わりに、波形が近いk人（本人を含む）の平均を使う |
| E3-noise | E3の拍に白色雑音を足す |
| E2-trim、E1-trim | 外れ具合が上位の人を除いてから、E2・E1を推定する |
| E2-agg | 被験者の平均の波形を、第1主成分の順にk人ずつの組の平均に置き換えてから、E2を推定する |
| E2-pc | 主成分を減らして E2 を推定する |
| E2-dp | 差分プライバシー付きのE2（7節） |

## 7. 差分プライバシー版

保証の根拠と、保証が及ばない範囲は [dp-guarantee.md](dp-guarantee.md) にまとめた。ここでは手順だけを書く。

### バイタルのL3・L4（`dpsynth.generate_dp`）

1. 被験者ごとの統計量 u_i（3変数の平均・log標準偏差、年齢、死亡退院の8次元）を、データから決めない公開の範囲（`STAY_BOX`）で [0, 1] に切り詰めて正規化する
2. 被験者内で標準化した系列のラグ0・ラグ1の共分散行列 C0_i、C1_i（3×3）を求め、各成分を [−1.01, 1.01] に切り詰める
3. 4つの総和 Σu_i、Σu_i u_iᵀ、ΣC0_i、ΣC1_i に、ガウス雑音を加える（`dpsynth.release`）
4. 雑音を加えた総和から、平均 μ・共分散 Σ（半正定値に射影）・VAR(1)の係数 A = C0⁻¹ C1・雑音の共分散を推定する
5. L4は、死亡退院の値で条件づけた多変量正規分布から被験者ごとの性質を引く。L3は、死亡退院・年齢と独立に引く
6. 4節と同じように系列を作り、値を公開の生理的な範囲（`vitals.BOUNDS`）で切り詰める

### 心電図のE2（`ecgdefense.generate("E2-dp")`）

1. 拍を、データに依存しない離散コサイン変換（DCT）の先頭20個の係数にする（主成分の基底はデータから作るので使わない）
2. 被験者ごとの平均の係数を L2 ノルム8で、拍ごとの残差を4で切り詰める。心拍間隔の平均を0.3〜2.0秒、標準偏差を0〜0.5秒に収める
3. 6つの総和（平均の係数、その外積、被験者内の残差の二次モーメント、心拍間隔の平均・その2乗・標準偏差）にガウス雑音を加える（`ecgdefense.dp_sums` の戻り値に加える）
4. 雑音を加えた総和から集団の分布を推定し、E2と同じように作る

## 8. 表データの逐次モデル（`syninf_tabular.fit_generate_parametric`）

Decruyenaere et al.（UAI 2024）の追試（GHE issue 1）で、統計モデルの代表として使った。著者の疾患データの生成過程と同じ構造を持つ。

1. 年齢 ~ 正規分布（平均・標準偏差をデータから推定）
2. 病期 | 年齢 ~ 比例オッズモデル（最尤推定、切片の順序を保つ）
3. バイオマーカー | 病期 ~ 病期ごとのガンマ分布（積率法）
4. 治療 ~ ベルヌーイ分布
5. 死亡 | 年齢・病期・治療 ~ ロジスティック回帰（ニュートン法）

この順に推定し、同じ順に生成する。

## 9. 再現のしかた

各作り方は、`uv run transyn` のコマンドから実行する（README と各レポートの再現手順）。学習データは `vitals-prepare`・`ehr-prepare`・`prepare` などで作り、乱数のシードを `--seed` で指定する。テストは `uv run pytest` で実行する。
