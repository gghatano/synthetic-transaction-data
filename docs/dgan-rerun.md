# DGANを適切な更新回数で再実験した結果

issue #17の成果物。ICUバイタルの検証（#15）で、gretel版DGANのバッチサイズを系列数より大きくしていたため、更新回数が足りていなかったことが分かった。過去のDGAN実験（Czech #2・#4・#5、EHR #10）も同じ設定だったので、バッチ64で更新回数を増やしてやり直し、結論が変わるかを確かめた。

## 要点

1. **Czechでは、取引の順序の再現が大きく改善し、論文のDGを上回った。** tcode 3-gramのJSDは0.268から0.096（3シードの平均、標準偏差0.014）になった。論文のDG（0.132）より良く、Banksformer（0.091）と同水準。#5の「論文DGの3-gramはどの設定でも再現できない」という結論は、学習不足によるものだった。
2. #5で見た崩壊は、更新回数を増やすと起きなくなった。取引間隔をlog変換しない設定と、開始日を属性から外す設定では、従来は全取引が同じ日に置かれた（月あたり件数74.5）。バッチ64ではそれぞれ2.6と2.9で、崩壊しなかった。系列の開始日が1998年に偏る崩壊も消えた。
3. **月内日のパターンは、更新回数を増やしても再現できなかった。** 月内日の分布（DoM）は0.110のままで、Banksformer（0.016）との差は変わらない。日付の扱いに専用の仕組みを持つBanksformerの優位は、学習量の差では説明できない。
4. **EHRでは、有用性がGPT型とほぼ同等になった。** 死亡退院予測のAUROCは0.506から0.650（標準偏差0.013）に上がり、GPT型（0.664）に並んだ。コード分布のJSDは0.224から0.017、コードと時間帯の同時分布は0.269から0.061に改善した。コードの並び（3-gram 0.352）はGPT型（0.221）にまだ及ばない。
5. シード間のばらつきは、EHRでは小さくなったが、Czechでは一部残った。Czechのシード0は取引密度が崩れ（月あたり件数のずれ18.2）、月次キャッシュフローも大きくずれた。平均すると月あたり件数のずれはむしろ悪化した（2.4から7.2）。

## 方法

| 実験 | 従来の設定 | 今回の設定 |
|---|---|---|
| Czech（#2・#4） | 長さ80の5,573系列、バッチ1,000、400エポック → 更新2,400回 | バッチ64、300エポック → 更新26,400回。3シード |
| DGANの切り分け（#5） | 同上 | 取引間隔をlog変換しない設定と、開始日を実データから抽出する設定を、バッチ64・300エポックで1シード |
| EHR（#10） | 長さ20の602系列、バッチ602、1,000エポック → 更新1,000回 | バッチ64、2,000エポック → 更新20,000回。3シード |

更新回数は、ICUバイタル（#15）でバッチ64・2,000エポック（約2.4万回）にしたのにそろえた。モデルの構成、前処理、評価指標、データ分割は元の実験と同じ。

実行手順は次のとおり。

```bash
for s in 0 1 2; do
  uv run transyn --seed $s fit dgan-b64 --epochs 300
  uv run transyn --seed $s ehr-fit dgan-b64 --epochs 2000
done
uv run transyn fit dgan-b64-rawtd --epochs 300
uv run transyn fit dgan-b64-empstart --epochs 300
uv run transyn evaluate
uv run transyn ehr-evaluate
```

所要時間（CPU 12コア、2本並行）は、Czechが1シード9〜13分、EHRが1シード約9分。

シードごとに見ると、バッチ64のTxPerMonthは18.25・2.66・0.74、CFは69,809・5,092・8,910で、シード0だけが大きく崩れている。

## 過去の結論への影響

| レポート | 従来の結論 | 再実験後 |
|---|---|---|
| Banksformer追試（#2） | DGANはDoMとCFで論文のDGと同じ傾向。3-gramは論文に届かない | DoMの傾向は同じ。3-gramは論文のDGを上回った |
| DGANの切り分け（#5） | 論文DGの3-gramはどの設定でも再現できない。取引間隔が0に潰れる崩壊が起きやすい | 3-gramは再現でき、崩壊も起きなかった。主因は学習不足だった |
| EHRの検証（#10） | PARとDGANは今回のデータ量では有用性が出ない | DGANはGPT型とほぼ同等の有用性を出した。PARの結論は変わらない |
| ICUバイタル（#15） | 変更なし（#15の時点でバッチ64を試している） | — |

各レポートには、この再実験へのリンクを追記した。

## 制約

- バッチサイズ以外の設定（学習率、sample_len、ネットワークの大きさ）は調整していない
- 切り分けの設定はシード0のみ
- Czechのシード0の取引密度の崩壊は、原因を調べていない
