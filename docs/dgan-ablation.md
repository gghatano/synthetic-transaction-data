# DGAN と論文 DG の差の切り分け

issue #5 の成果物。#2 の追試（[replication-banksformer.md](replication-banksformer.md)）では、gretel 版 DGAN は論文の DG と
DoM・CF の傾向は一致したが、Tcode 3-gram と (Tcode, DoM) が一致せず、系列開始日（属性）も 1998 年 5 月以降に崩壊していた。
設定を 1 つずつ変えて、どこに原因があるかを調べた。

## 要点

1. **gretel 版 DGAN はシード間のばらつきが大きく、論文の DG との差を設定の違いに帰着できない。** 同じ設定でもシードによって金額の平均が実データの 0.3〜6.6 倍、取引間隔の W1 距離が 2.4〜24.0 と大きく変わる。論文値との差よりシード間の差のほうが大きい指標が多い。
2. **どの設定でも Tcode 3-gram は論文の DG（0.132）に届かなかった。** 最良はシード 1 の 0.209 で、tcode をシャッフルした基準（0.186）より悪い。取引コードの順序は学習できていない。
3. **取引間隔は「0 に潰れる」崩壊が起きやすい。** 取引間隔を log 変換しない場合と、開始日を属性から外した場合の 2 つで、生成された取引間隔がすべて 0 になった（TD が実データの平均取引間隔 5.28 と一致し、月あたり件数は 74.5）。
4. **DoM が良く見える崩壊がある。** 開始日を実データから抽出した設定は DoM 0.021 と論文の BF 並みに見えるが、全取引が実データの開始日と同じ日に置かれた結果で、日付パターンを学習したわけではない。DoM だけを見ると誤判定する。
5. **エポック数を増やしても改善しない。** 1000 エポックでは 3-gram が 0.462 に悪化し、開始日の崩壊も残った。

## 方法

基準は #2 の DGAN（gretel-synthetics 0.22.2、400 エポック、取引間隔は log1p、開始日は属性として生成、sample_len 10）。
ここから 1 点ずつ変えた設定を、シード 0 で学習・生成した（5,000 系列）。基準の設定のみシード 0〜2 の 3 回（#4）。

| 名前 | 変更点 |
|---|---|
| dgan | 基準 |
| dgan-rawtd | 取引間隔を log 変換せずに渡す |
| dgan-empstart | 開始日を属性から外し、生成後に学習データの系列開始日から復元抽出する（論文の BF・TG と同じ扱い） |
| dgan-sl5 | sample_len を 10 → 5（1 回の RNN ステップで生成する取引数を減らす） |
| dgan-e1000 | エポック数を 400 → 1000 |

実行:

```bash
uv run transyn fit dgan-empstart --epochs 400
uv run transyn fit dgan-sl5 --epochs 400
uv run transyn fit dgan-rawtd --epochs 400
uv run transyn fit dgan --epochs 1000 --tag=-e1000
uv run transyn evaluate
```

### 読み取り

- **シード間のばらつき**: 基準設定の 3 シードで、Amt は 5,058〜33,457、CF は 6,883〜94,795、TD は 2.43〜23.99 と 1 桁の幅がある。シード 2 は取引間隔が長すぎる側に崩れ（TD 24.0）、シード 0 は開始日が 1998 年に偏った。論文 DG との差（Amt 1,939、CF 57,800）はこの幅に収まっている指標もあり、差の原因を特定の設定に帰着できない。
- **取引間隔の崩壊**: dgan-rawtd と dgan-empstart はどちらも TD = 5.28（実データの平均取引間隔と同じ値）、TxPerMonth = 74.5 で、80 件すべてが同じ日に置かれている。log 変換は #2 で入れた対策で、外すと崩壊が再発した。開始日を属性から外すと log 変換していても崩壊したので、属性の有無が学習の安定性に影響している。
- **見かけの DoM 改善**: dgan-empstart の DoM 0.021 は、全取引が実データの開始日に置かれたことによるもので、TD・TxPerMonth を見れば崩壊が分かる。#2 で述べたとおり、単一の指標で時間構造を判定するのは危険。
- **sample_len**: 5 にすると TD と TxPerMonth は最良になったが、3-gram は 0.269 に悪化し、開始日の崩壊は残った。
- **エポック数**: 1000 エポックでは 3-gram（0.462）・TcodeDoM（0.345）ともに悪化した。学習を長くしても順序の学習には効かない。

## 結論

- gretel 版 DGAN では、論文の DG の 3-gram（0.132）は今回試したどの設定・シードでも再現できなかった。
- 差の主因は特定の設定ではなく、gretel 版 DGAN の学習の不安定さ（シード・設定によって取引間隔・開始日・金額が別々に崩壊する）にあると考える。論文の元実装（TensorFlow 版、可変長系列）との差は切り分けていない。
- 実務的には、DGAN の結果は複数シード・複数の時間構造指標で確認しないと、崩壊を見逃す。
