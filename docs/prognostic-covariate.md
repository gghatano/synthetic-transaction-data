# 外部データの予後予測を共変量にして必要な被験者数を減らす

GHE issue 2の成果物。合成データで被験者を水増ししても推論の情報は増えない（GHE issue 1、[synthetic-inference.md](synthetic-inference.md)）。人数を減らせるのは外部の情報を持ち込む場合で、臨床試験では、過去のデータで学習した予後予測を共変量にするPROCOVA（Schuler et al., Int J Biostat 2021）が2022年に欧州医薬品庁に認められている。被験者ごとの時系列で、これがどれだけ効くかを半合成実験で確かめた。

## 要点

1. **第1種の過誤率は、どの解析でも5%前後に保たれた。** 3通りの病院の分け方、5通りの人数、1,000回ずつの試行で、平均心拍数では3.9〜6.8%、心拍数のばらつきでは1.6〜5.6%だった。予後予測を外部データで学習しても、合成データで学習しても、検定の妥当性は崩れない。
2. **人数を最も減らしたのはベースライン調整だった。** 前半6時間の平均心拍数を共変量にしたANCOVAで、効果5 bpmを検出力80%で見つけるのに必要な人数は約404人から約93人（−77%）になった。前半と後半の相関が0.88と高く、分散比は目安の式 (1−ρ²) = 0.23 とよく一致した。
3. **外部データの予後予測は、そこからさらに約24%減らした。** 別の病院のデータで学習した線形の予後予測（前半6時間の3変数の要約と年齢を使う）は、後半との相関が0.91で、必要人数は約71人になった。n=100での検出力は、ベースライン調整の81%に対して90%。
4. **外部データの代わりに合成データで学習すると、上乗せの削減は消えた。** 外部データをVAR(1)で合成し、それで予後予測を学習すると、必要人数は約95人でベースライン調整と同じになった。PARで合成した場合は相関が0.64に落ち、必要人数は約247人とベースライン調整より悪くなった。外部データを合成データとしてしか受け取れない場合、予後予測の改善分は合成で失われやすい。
5. **結果がばらつき（心拍数のlog標準偏差）の場合、外部の予後予測は効かなかった。** ベースラインの同じ量での調整は分散を35%減らしたが、外部データの予後予測は9〜23%しか減らさず、ベースライン調整より悪かった。予測しやすい結果でなければ、外部データを使っても人数は減らない。

## 方法

### データ

- eICU Demo v2.0.1の定期バイタル（公開リポジトリの#15と同じ前処理）。心拍数・SpO2・呼吸数を5分刻みにした入室から12時間の系列（144点）、1,422滞在
- 前半6時間（72点）をベースライン、後半6時間を結果の期間とする
- 病院（`hospitalid`、182病院、1病院あたり最大16滞在）をランダムな順に並べ、滞在数が半分に達するまでを「外部」、残りを「対象」とした。分け方0では外部715滞在（95病院）・対象707滞在（87病院）。分け方は3通り（シード0〜2）

### 半合成実験

1回の試行は次のとおり。

1. 対象から n 人（20・40・60・100・200）を抜き、ランダムに半分ずつ2群に分ける
2. 片方の群の結果に既知の効果 δ を足す。δ = 0（第1種の過誤率を測る）と、平均心拍数で5 bpm、心拍数のlog標準偏差で0.2（標準偏差で約22%の変化）
3. 群の差を、次の解析で推定・検定する

| 解析 | 共変量 | 外部データ |
|---|---|---|
| unadjusted | なし（2群のt検定と同じ） | 使わない |
| baseline | 前半6時間の同じ量（平均心拍数、またはlog標準偏差） | 使わない |
| prog-linear | 外部データで学習したリッジ回帰の予測 | 実データ |
| prog-gbm | 外部データで学習した勾配ブースティングの予測 | 実データ |
| prog-syn-var1 | 外部データをVAR(1)で合成し、それで学習したリッジ回帰の予測 | 合成データ |
| prog-syn-par | 外部データをPAR（200エポック）で合成し、それで学習したリッジ回帰の予測（分け方0のみ） | 合成データ |

予後予測の入力は、前半6時間の3変数ごとの平均・標準偏差・最小・最大・傾き・ラグ1自己相関と年齢（公開リポジトリの#15の要約特徴量と同じ）。予後予測はベースラインだけから作るので、足した効果の影響を受けない。

条件ごとに1,000回繰り返した。必要人数（n80）は、標準誤差が 1/√n に比例するとして n80 = n × (SE × (z₀.₉₇₅ + z₀.₈) / δ)² で見積もった。

実行手順は次のとおり。

```bash
uv run transyn vitals-prepare
uv run transyn --seed 0 prognostic-run --ns 20 40 60 100 200 --reps 1000
uv run transyn --seed 1 prognostic-run --ns 20 40 60 100 200 --reps 1000 --score-kinds prog-linear prog-gbm prog-syn-var1
uv run transyn --seed 2 prognostic-run --ns 20 40 60 100 200 --reps 1000 --score-kinds prog-linear prog-gbm prog-syn-var1
```

所要時間（CPU、他の実験と並行）は、分け方0がPARの学習を含めて約50分、分け方1・2が各数分。

## 結果

### 予後予測と結果の相関（対象の全被験者、3通りの分け方の平均）

| 解析 | 平均心拍数 | 心拍数のlog標準偏差 |
|:--|--:|--:|
| baseline | 0.878 | 0.505 |
| prog-linear | 0.908 | 0.276 |
| prog-gbm | 0.892 | 0.423 |
| prog-syn-var1 | 0.875 | 0.057 |
| prog-syn-par（分け方0） | 0.636 | 0.176 |

### 平均心拍数（δ = 5 bpm）

3通りの分け方の平均。括弧内は分け方による範囲。

| 解析 | 第1種の過誤率 | 検出力 n=40 | 検出力 n=100 | 調整なしとの分散比（n=100） | 必要人数 n80 |
|:--|--:|--:|--:|--:|--:|
| unadjusted | 0.053 | 0.143 | 0.295 | 1.000 | 404（373〜428） |
| baseline | 0.052 | 0.434 | 0.812 | 0.231 | 93（92〜95） |
| prog-linear | 0.052 | 0.543 | 0.897 | 0.176 | 71（68〜73） |
| prog-gbm | 0.049 | 0.487 | 0.846 | 0.205 | 83（78〜86） |
| prog-syn-var1 | 0.051 | 0.426 | 0.806 | 0.236 | 95（90〜103） |
| prog-syn-par（分け方0） | 0.049 | 0.184 | 0.441 | 0.600 | 247 |

第1種の過誤率は5通りの人数の平均。人数ごとの値は3.9〜6.8%の範囲。

### 心拍数のlog標準偏差（δ = 0.2）

| 解析 | 第1種の過誤率 | 検出力 n=100 | 検出力 n=200 | 調整なしとの分散比（n=100） |
|:--|--:|--:|--:|--:|
| unadjusted | 0.035 | 0.193 | 0.258 | 1.000 |
| baseline | 0.039 | 0.265 | 0.345 | 0.650 |
| prog-linear | 0.037 | 0.213 | 0.269 | 0.912 |
| prog-gbm | 0.038 | 0.229 | 0.304 | 0.771 |
| prog-syn-var1 | 0.035 | 0.193 | 0.265 | 0.992 |
| prog-syn-par（分け方0） | 0.036 | 0.202 | 0.251 | 0.977 |

この結果では、n80の見積もりがnによって変わった（調整なしでn=20から約1,000、n=200から約1,700）。分布の裾が重く、少人数の標本では標準誤差が小さめに出るためで、1/√n の仮定が成り立たない。検出力の実測値で読む。第1種の過誤率も名目より低め（保守的）だった。

### 読み取り

- 分散比は (1−ρ²) とほぼ一致した。平均心拍数では、ρ=0.878 の予測 0.229 に対して実測 0.231、ρ=0.908 の予測 0.176 に対して実測 0.176。どれだけ人数が減るかは、予後予測と結果の相関でほぼ決まる。
- ベースラインの測定があれば、それだけで分散は1/4以下になる。外部データの予後予測が上乗せできたのは、3変数の要約と年齢を組み合わせて、相関を0.88から0.91に上げた分だけだった。
- VAR(1)の合成データで学習した予後予測は、平均心拍数ではベースラインと同程度、ばらつきではほぼ情報がなかった（相関0.06）。VAR(1)は滞在内の変動を定常な1次の自己回帰で作るので、前半と後半のばらつきの結びつきを持たない。合成データで学習した予後予測は、生成モデルが再現した関係しか使えない。
- PARの合成データでは、平均心拍数の相関も0.64に落ちた。公開リポジトリの#15で見た「PARは滞在ごとの平均を十分に再現できない」ことが、予後予測の質に直接響いた。

## 実験への示唆

- 必要な被験者数を減らす第一の手段は、介入・条件の前にベースライン期間を測ることだった。合成データや外部データより効果が大きい。
- 過去の実験データや近い公開データがあれば、予後予測を共変量にして、さらに2割程度減らせる可能性がある。第1種の過誤は保たれるので、事前に予後予測と解析方法を決めておけば使える。
- 外部データを合成データとしてしか受け取れない場合、上乗せの削減はほぼ得られないと考えたほうがよい。少なくとも、合成データで学習した予後予測の相関を実データで確かめる必要がある。
- 結果が変動の大きさのように予測しにくい量では、外部の予後予測は効かなかった。人数の見積もりは、結果の種類ごとに行う必要がある。

## 制約

- 半合成実験で、効果は結果の尺度に一定量を足して作った。実際の介入では効果が被験者ごとに異なり、ベースラインと交互作用を持つことがある
- ICUの患者の入室直後の12時間で、実験の被験者とは状態も記録の条件も違う
- 外部と対象は同じeICU Demoの別の病院で、分布が近い。外部データが別の施設・別の測定条件のものなら、相関は下がる
- PARで合成した場合は分け方0の1回だけ
- 予後予測の学習方法は2種類（リッジ回帰、勾配ブースティング）だけで、系列そのものを入力にするモデルは試していない
- 既存のレポート（公開リポジトリの#10・#15）では eICU Demo を「20病院」としていたが、v2.0.1の`patient.csv`は2,520滞在・186病院（`hospital.csv`も186行）で、今回の1,422滞在は182病院にまたがる
