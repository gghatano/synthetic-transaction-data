# 予測モデルの学習で合成データは実データ何人分になるか

GHE issue 8の成果物。合成データで被験者を水増ししても、検定の情報は増えなかった（GHE issue 1、[synthetic-inference.md](synthetic-inference.md)）。一方、予測モデルの学習では、データ拡張で数ポイントの性能向上が報告されている。被験者ごとの時系列で、データ拡張や合成データが「実データ何人分」に相当するかを学習曲線で測った。

## 要点

1. **同じ人数から作った合成データで、少人数の予測モデルは良くなった。** 実データ n 人で学習したVAR(1)の合成データ（4n人分）を足すと、低酸素の予測のAUROCはn=20で0.753から0.800、頻脈で0.854から0.901になった。それぞれ実データ約49人分・60人分に相当する。n=100では低酸素で約133人分、n=400では約365人分で、人数が増えるほど効果は薄れた。
2. **この効果は正則化では説明できなかった。** 実データだけでロジスティック回帰の正則化を強めても（C = 0.003〜0.03）、n=20のAUROCは0.754・0.853までしか上がらなかった。VAR(1)は「後半は前半と同じ性質の続き」「被験者ごとの性質は正規分布」という構造を持ち込み、それが予測に役立つ仮定として働いたと考えられる。情報が増えたのではなく、仮定が足されている。仮定がおおむね正しいから効き、人数が増えると実データが仮定を上回る。
3. **単純な変換による拡張（ノイズと振幅の拡大縮小）は、かえって性能を下げた。** n=40で実データ約25〜30人分。ラベルを決める後半の系列は変えずに入力だけを揺らすので、入力とラベルの関係が弱まる。
4. **外部の実データを足すのが最も効いた。** 別の病院の実データ400人を足すと、n=20でも低酸素で実データ約278人分、頻脈では実データだけの400人を上回った。外部データをVAR(1)の合成データで受け取った場合、n=20で低酸素は約62人分、頻脈は約247人分で、外部の実データの効果（AUROCの上がり幅）の67%と94%が残った。
5. **合成データのラベルの割合は実データとずれた。** 合成系列の後半から同じ定義で決めた低酸素の割合は、実データの14〜17%に対して、VAR(1)で31〜33%、PARで0.6〜14%（病院の分け方による）だった。PARの合成データは低酸素の例をほとんど含まないことがあり、足しても効果がなかった。

## 方法

### データと課題

- eICU Demo v2.0.1の定期バイタル（公開リポジトリの#15と同じ前処理）、1,422滞在
- 病院単位で外部・対象に分ける（GHE issue 2と同じ、3通りの分け方）。対象から評価用300人を固定で取り分け、残り（約400人）から学習用に n 人（20・40・60・100・200・400）を抜く
- 課題: 前半6時間の系列から、後半6時間に次のイベントが起きるかを予測する
  - desat: SpO2 92%未満が30分（6点）以上（対象の病院で15〜17%）
  - tachy: 心拍数110超が30分以上（14〜18%）
- 予測モデル: 前半6時間の3変数ごとの平均・標準偏差・最小・最大・傾き・ラグ1自己相関と年齢（#15と同じ要約特徴量）の、標準化したロジスティック回帰（C = 0.1）
- 評価: 評価用300人でのAUROC。条件ごとに100回抜き直し、3通りの分け方で平均した

### 学習データに足すもの

| 手法 | 足すもの | ラベル |
|---|---|---|
| real | なし | — |
| jitter | 実データ n 人の前半の系列に、変数ごとの標準偏差の3%のノイズを足し、振幅を N(1, 0.05²) 倍したものを4件ずつ（4n件） | 元の人のラベル |
| var1-same | 同じ n 人で学習したVAR(1)の合成データ4n人分 | 合成系列の後半から決める |
| var1-ext | 外部の病院（約710人）で学習したVAR(1)の合成データから400人分 | 同上 |
| par-ext | 外部の病院で学習したPAR（200エポック）の合成データから400人分 | 同上 |
| ext-real | 外部の病院の実データ400人 | 実データのラベル |

対照として、実データだけでロジスティック回帰の正則化の強さを変えた場合（C = 0.003・0.01・0.03・0.1・1）も測った。

実データ換算の人数は、3通りの分け方で平均した real の学習曲線を log n で線形補間し、同じAUROCを出すのに必要な実データの人数として求めた。曲線の範囲（AUROC 0.753〜0.848、0.854〜0.933）の外は求めない。

実行手順は次のとおり。

```bash
uv run transyn vitals-prepare
for s in 0 1 2; do
  uv run transyn --seed $s augment-run --ns 20 40 60 100 200 400 --reps 100
  uv run transyn --seed $s augment-regcheck --ns 20 40 60 100 200 400 --reps 100
done
```

所要時間（CPU、3本並行）は、PARの学習と生成を含めて1本約50分。正則化の対照は数分。

### 読み取り

- var1-sameの効果は、どの正則化の強さでも実データだけでは届かない水準だった（n=20で0.800に対して最良0.754）。VAR(1)の合成データは、前半の要約統計と後半のイベントの関係を「定常な線形・正規のモデルが言う関係」としてたくさん示す。予測モデルはその関係を学ぶので、少人数で推定がぶれやすい係数が、モデルの仮定に沿って安定する。
- ただし、var1-sameの効果は分け方による違いが最も大きかった（desatで標準偏差約0.03）。仮定が対象の病院のデータに合うかどうかで、効き方が変わる。
- VAR(1)の合成データは、低酸素の割合が実データの約2倍だった。VAR(1)はSpO2の変動を対称な正規分布で作るので、100%に張り付いた系列の下向きの揺れを過大に作る。それでもAUROC（順位の指標）は改善した。予測確率をそのまま使う用途では、較正がずれる。
- PARの合成データは、分け方0と2で低酸素の例がほとんどなく（0.6%・0.9%）、desatの予測には効かなかった。公開リポジトリの#15で見たとおり、PARは被験者ごとの違いや変動の形を十分に再現しない。
- jitterは、ラベルの元になる後半を変えずに前半だけを揺らすので、入力とラベルの対応が弱まる。生体信号の分類で報告される拡張の効果は、ラベルが系列全体の性質（不整脈の有無など）で、揺らしても変わらない課題でのものが多い。今回のように将来のイベントを予測する課題では、単純な拡張は逆効果になりうる。
- 外部の実データは、n=20でも実データだけのn=200〜400と同等以上だった。同じ課題の実データを増やすことに勝る方法はなかった。

## 実験への示唆

- 予測モデルを少人数で作る場合、構造の仮定がおおむね正しい統計モデル（今回はVAR(1)）の合成データを足すと、性能が上がることがある。ただしこれは仮定を足しているのであって、情報が増えたわけではない。仮定が外れれば逆効果になりうるので、評価は必ず実データで行う。
- 検定・推定（GHE issue 1）と予測（今回）では、合成データの働きが違う。検定では合成データで人数を増やしても情報は増えず偽陽性が増える。予測では、生成モデルの仮定が正則化以上の働きをすることがある。
- 単純な変換による拡張は、課題によっては性能を下げる。ラベルが入力の変換で変わらない課題かを確かめてから使う。
- 外部データを使えるなら、合成データよりも実データのまま使う（共同研究の枠組みなどで）ほうが効果が大きい。合成データでしか受け取れない場合も、統計モデルの合成データなら効果の7〜9割が残った。

## 制約

- 予測モデルは要約特徴量のロジスティック回帰だけ。系列を直接入力にする深層学習のモデルでは、拡張の効き方が変わり得る
- 課題は2つ（後半の低酸素・頻脈）。前半の延長で予測しやすい課題なので、定常性を仮定するVAR(1)に有利だった可能性がある
- 単純な変換はノイズと振幅の拡大縮小だけで、時間の伸縮や切り出しは試していない
- 合成データの量は固定（同じ人数からは4n人分、外部からは400人分）
- DGANは、少人数で学習データを覚えるため（GHE issue 3）試していない
