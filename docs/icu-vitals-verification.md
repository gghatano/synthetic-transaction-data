# eICU DemoでのICUバイタル時系列の合成の検証

issue #15の成果物。#10のEHRイベント系列に続き、信号に近い等間隔の多変量時系列で生成手法を比べた。目的はこれまでと同じくデータ共有で、忠実度・有用性・プライバシを評価した。

## 要点

1. **どの生成モデルも、実データと見分けられる合成データしか作れなかった。** 要約特徴量で実データと合成データを分類すると、判別スコア（正解率−0.5）はどのモデルも0.44〜0.50だった。実データ同士では0.000。学習用716滞在という規模では、信号に近いデータの合成はイベント系列より難しい。
2. **単純な統計モデル（VAR(1)）が多くの指標で深層モデルを上回った。** 値の分布、変数間の相関、滞在ごとの平均、判別スコア、有用性（TSTR 0.599）で最も良かった。比較の物差しとして入れたモデルが最良になったことは、今回の深層モデルがこのデータ量では十分に学習できていないことを示す。
3. **時間構造を再現した深層モデルも、患者ごとの違いは再現できなかった。** 更新回数を増やしたDGANとPARは自己相関を時刻シャッフルの0.44から0.16前後まで下げたが、滞在ごとの平均のずれは0.48〜0.73で、滞在シャッフル（0.57）と同程度だった。
4. **行独立のCTGANは、3つ目のテーマでもシャッフルした実データとほぼ同じ振る舞いをした。** 自己相関は時刻シャッフル並み、滞在ごとの平均は滞在シャッフル並みで、有用性はAUROC 0.338だった。トランザクション（#2）、EHR（#10）と同じ結果。
5. **DGANは更新回数が足りないと大きく崩れる。** 既定の設定（バッチ1,000）では、716系列に対して1エポック1回しか更新されず、値の分布も死亡退院の割合も大きくずれた。バッチを64にすると時間構造は改善した。過去のDGANの結果（#2、#5、#10）も同じ理由で学習不足だった可能性があり、各レポートに注記した。

## 方法

### データ

- eICU Collaborative Research Database Demo v2.0.1（PhysioNet、ODbL v1.0）の定期バイタル（`vitalPeriodic`、5分間隔）
- 変数は記録率の高い心拍数・SpO2・呼吸数の3つ。ICU入室から12時間を5分刻みにした144点の系列にした
- 生理的にありえない値（心拍数20〜250、SpO2 50〜100、呼吸数3〜60の範囲外。多くは0）は欠測として扱った
- 3変数とも8割以上記録のある滞在に限り、残りの欠測は滞在内で線形補間した → 1,422滞在
- 属性は年齢と死亡退院
- 患者単位で分割: A（学習, 716滞在）/ B（評価・非メンバー, 354）/ C（実データの基準, 352）。死亡退院の割合は7.0〜10.7%

### 手法

| 手法 | 設定 | 系統 |
|---|---|---|
| ctgan | SDV CTGAN、300エポック、`log_frequency=False`。1行=1時点（時刻番号も列にする）。時刻番号ごとに条件付きで生成し、ランダムに束ねて系列にする | 行独立 |
| dgan | gretel版DoppelGANger、2,000エポック、バッチ1,000（716系列なので1エポック1回の更新）、sample_len 6 | 系列GAN |
| dgan-b64-e2000 | 同上でバッチ64（1エポック12回の更新）、2,000エポック | 系列GAN |
| dgan-b64 | バッチ64、500エポック（シード0のみ） | 系列GAN |
| par | SDV PAR、50エポック。年齢・死亡退院をコンテキスト | 自己回帰（RNN） |
| par-e200 | 同上、200エポック | 自己回帰（RNN） |
| var1 | 比較用の統計モデル。滞在ごとの平均・log標準偏差・年齢を死亡退院の有無ごとに多変量正規分布で引き、滞在内の変動を変数間のVAR(1)で生成する | 統計モデル |

生成数は学習データと同じ716滞在。dgan-b64以外は3シード（0〜2）の平均。CPUのみ。

### 評価

| 軸 | 指標 | 定義 |
|---|---|---|
| 忠実度 | Marg | 変数ごとの値の分布のWasserstein-1距離（実データで標準化）の平均 |
| | Corr | 変数間の相関係数の差の平均 |
| | ACF | 滞在内の自己相関（ラグ5分・30分・1時間）の差の平均 |
| | PSD | 滞在内の変動のパワースペクトル（対数）の差の平均 |
| | StayMean / StayStd | 滞在ごとの平均・標準偏差の分布のWasserstein-1距離 |
| | Disc | 判別スコア。要約特徴量で実データと合成データを分類したときの交差検証の正解率−0.5（0が理想。0.5を下回る場合は0） |
| | Mortality | 死亡退院の割合の差 |
| 有用性 | TSTR_AUROC | 生成データで死亡退院の予測（ロジスティック回帰、特徴量は変数ごとの平均・標準偏差・最小・最大・傾き・ラグ1自己相関と年齢）を学習し、実データBで評価したAUROC |
| プライバシ | DCRRatio | 合成→学習データの最近傍距離の中央値を、B→学習データの値で割った比 |
| | MIA | 学習データ（メンバー）とB（非メンバー）を、最も近い合成系列までの距離で見分けたときのAUC（0.5が理想） |
| | NearCopy | 学習データとの最近傍距離が「B→学習データ」の距離の1パーセンタイルより小さい合成系列の割合 |

基準として、実データC、Cの時刻の順を滞在内で入れ替えたもの（時刻シャッフル）、同じ時刻の値を滞在間で入れ替えたもの（滞在シャッフル）、学習データAのコピーを並べた。

### 読み取り

- 判別スコア: 実データ同士が0.000なのに対し、生成モデルは0.444〜0.500。最良のvar1でも分類器は94%の正解率で見分けた。イベント系列（#10）では判別スコアを測っていないので直接は比べられないが、今回はどのモデルも「本物らしい」合成データには届いていない。
- var1: 単純な統計モデルが、値の分布・相関・滞在ごとの平均・死亡退院の割合・有用性で最も良かった。滞在ごとの性質（平均・ばらつき）を死亡退院の有無で分けて引いているためで、深層モデルはこの滞在単位の構造を学習できていない。一方、滞在内の変動を線形の1次自己回帰で作るため、スペクトル（1.319）はPAR（0.700）に劣る。
- DGAN: 既定の設定では更新が2,000回しかなく、値の分布（1.461）と死亡退院の割合（0.163のずれ）が大きく崩れた。バッチ64で更新を24,000回に増やすと、自己相関は0.160と全モデル中最良になった。ただし値の分布と相関はむしろ悪化し、シード間のばらつきも大きい。
- PAR: エポックを50から200に増やすと、相関（0.194 → 0.057）・自己相関（0.403 → 0.165）・スペクトル（1.416 → 0.700）が大きく改善した。滞在ごとの平均（0.478）は滞在シャッフル（0.572）より少し良い程度。
- CTGAN: 自己相関0.445（時刻シャッフル0.444）、滞在ごとの平均0.598（滞在シャッフル0.572）で、時点を独立に生成したことの帰結がそのまま出ている。
- 有用性: 実データで学習するとAUROCは0.744〜0.776だが、生成モデルでは最良のvar1でも0.599。評価用Bの死亡は38件しかなく、AUROCの標準誤差は約0.05ある。0.5を下回る値（ctgan 0.338など）は当て推量と区別できないと読むのが妥当。実データでも死亡退院と個々の特徴量の相関は±0.1程度と弱く、生成モデルはこの弱い関係を引き継げていない。
- プライバシ: メンバーシップ推論のAUCはどのモデルも0.474〜0.483で、実データC（0.492）と差がない。学習データにごく近い系列の割合（NearCopy）も0.000〜0.020で、実データC（0.031）以下。今回の生成モデルは学習データをコピーしていないが、忠実度自体が低いため、プライバシが守られているというより、漏らすほど学習できていないと読むべき。

## データ共有に向けた示唆

- 信号に近い時系列では、このデータ量（学習716滞在）だと、深層生成モデルは単純な統計モデルに勝てなかった。共有用の合成データを作るなら、まず統計モデルを基準に置き、深層モデルがそれを超えるかで判断する。
- 時間構造（自己相関・スペクトル）と患者ごとの違い（滞在ごとの平均・ばらつき）は、別々に崩れる。どちらか一方の指標だけでは評価できない。
- プライバシ指標が良いことと、合成データが役に立つことは別。忠実度・有用性と並べて読む必要がある。

## 制約

- データが小さい（学習716滞在、評価354滞在・死亡38件）。eICU本体（約20万滞在）では深層モデルの結果が大きく変わり得る
- 変数は3つ、期間は入室後12時間に限った。欠測は線形補間しており、欠測パターンそのものは再現の対象にしていない
- 拡散モデル（TimeDiffなど）やTimeGANは試していない
- 判別スコアは要約特徴量に基づく。系列そのものを入力にする分類器（RNNなど）なら、さらに見分けやすくなる可能性がある

## 関連研究

- RCGAN（Esteban, Hyland, Rätsch 2017, https://arxiv.org/abs/1706.02633 ）: 医療時系列のGANの先駆けで、eICUのバイタル（SpO2・心拍数・呼吸数・平均血圧）を対象にした
- TimeDiff（JAMIA 2024, https://academic.oup.com/jamia/article/31/11/2529/7747780 ）: EHR時系列の拡散モデル。TimeGANなどを上回ったと報告している
- 医療時系列の合成手法の比較（PMC10826010, https://pmc.ncbi.nlm.nih.gov/articles/PMC10826010/ ）: 患者のメタデータを使った合成手法を比較している

## 再現手順

```bash
# eICU Demo（https://physionet.org/content/eicu-crd-demo/2.0.1/）を data/eicu_demo/ に展開しておく
uv run transyn vitals-prepare
for s in 0 1 2; do
  uv run transyn --seed $s vitals-fit ctgan --epochs 300
  uv run transyn --seed $s vitals-fit dgan --epochs 2000
  uv run transyn --seed $s vitals-fit dgan-b64 --epochs 2000 --tag=-e2000
  uv run transyn --seed $s vitals-fit par --epochs 50
  uv run transyn --seed $s vitals-fit par --epochs 200 --tag=-e200
  uv run transyn --seed $s vitals-fit var1 --epochs 0
done
uv run transyn vitals-fit dgan-b64 --epochs 500
uv run transyn vitals-evaluate
```

所要時間（CPU 12コア、他の学習と並行実行の場合を含む）: CTGAN 約40分（並行実行が重なった回は約110分）、DGAN 約7分（バッチ64・2,000エポックは約14分）、PAR 約6分（200エポックは約13分）、VAR(1) 約10秒。
