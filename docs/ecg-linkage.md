# 心電図の合成データのそれっぽさと本人との紐づき

GHE issue 17の成果物。心電図は生体認証に使われ、個人識別の正解率は90%超と報告されている。一方、合成心電図を個人識別器で照合して攻撃した査読論文は、調べた範囲（2026-10-15）では見つからなかった。心電図の合成データを公開する前に、「それっぽさ（本物らしさ）」「本人との紐づき」「有用性」を同じ物差しで測った。

## 要点

1. **実データの心電図は、別の記録からほぼ本人を特定できた。** 合成に使う側の記録を、別の記録で登録した識別器（主成分＋収縮つき線形判別分析）にかけると、被験者単位の正解率はECG-IDで94.5%（89人、当て推量1.1%）、MIT-BIHで97.1%（43人）だった。
2. **本人ごとに作る合成は、ほぼ本人に結びついた。** 本人の平均の波形と拍ごとのゆらぎから作る合成（E3、デジタルツイン型）では、合成の被験者が元の本人と判定された割合がECG-IDで86%、MIT-BIHで97%だった。合成に使った人かどうかを当てるAUCは0.95と1.00。実データをそのまま出す場合（94.5%・97%）とほとんど変わらない。
3. **集団の分布から作る合成は、全体では当て推量に近いが、外れた波形の人に紐づきが集中した。** 被験者ごとの平均の波形を集団の多変量正規分布から引く合成（E2）のAUCは、ECG-IDで0.545、MIT-BIHで0.637。外れ具合の上位20%の人に限るとECG-IDで0.60、MIT-BIHで0.86だった（それ以外は0.53・0.60）。全員が集団の平均の形になる合成（E1）でも、MIT-BIHの外れた人では0.76だった。
4. **それっぽい作り方ほど、本人に紐づいた。** 実データと合成を見分ける判別スコア（0が本物並み、被験者単位の交差検証）は、ECG-IDでE3が0.15、E2が0.23、E1が0.42、力学系モデル（ECGSYN、E0）が0.47で、紐づきのAUCはその逆の順（0.95、0.55、0.56、0.52）だった。データを使わない力学系モデルは紐づかないが、ほぼ完全に見分けられた。
5. **拍の分類の有用性は、本人の特徴がなくても落ちなかった。** MIT-BIHで、正常拍と心室性期外収縮拍の分類を合成データで学習し、合成に使っていない人の実データで評価したAUROCは、E1が0.785、E2が0.776、E3が0.755で、メンバーの実データで学習した場合（0.710）以上だった。分け方による差は大きい（実データで0.53〜0.78）。

## 方法

### データ

| データ | 被験者 | 記録 | 合成に使う側（gen） | 攻撃者の登録用（enroll） |
|---|---|---|---|---|
| ECG-ID Database v1.0.0（PhysioNet、ODC-By） | 89人（登録用の記録がある人） | 1人2〜20回、20秒、I誘導（フィルタ済み）、500Hz | 1回目の記録 | 2回目以降の記録 |
| MIT-BIH Arrhythmia Database v1.0.0（PhysioNet、ODC-By） | 43人（MLII誘導の記録。ペースメーカーの4記録を除く） | 30分、360Hz、拍ごとの種類の注釈 | 前半15分 | 後半15分 |

- 拍の切り出し: R波の前0.25秒〜後0.45秒を0.5〜40 Hzに絞り、128点に揃えて窓の中央値を引く。ECG-IDはR波を自前の検出器（Pan-Tompkins法の流れ）で、MIT-BIHは注釈の位置で取る
- WFDB形式の読み込み・注釈・R波の検出は、依存を増やさないため numpy・scipy で実装した
- 被験者を半分ずつメンバー（合成に使う）と非メンバーに分ける。分け方は5通り

### 合成の作り方

拍の主成分（20個）の係数の空間で作る。合成の被験者はメンバーと同じ人数、1人あたりECG-IDで24拍、MIT-BIHで200拍。

| 作り方 | 内容 | データの使い方 |
|---|---|---|
| copy | メンバーの拍をそのまま出す | 最悪の場合の目安 |
| E0 | 心電図の力学系モデル（ECGSYN、McSharry et al. 2003）を論文の既定のパラメータで動かし、P・Q・R・S・T波の振幅を±10%ゆらす | 拍の振幅の大きさ（集団の中央値）だけ |
| E1 | 集団の平均の波形＋被験者内のゆらぎ（全員が同じ形） | 集団の平均と被験者内の共分散 |
| E2 | 被験者ごとの平均の波形を、集団の多変量正規分布（収縮推定）から引き、被験者内のゆらぎを加える | 集団の平均・被験者間の共分散・被験者内の共分散（見本用データのL3に当たる） |
| E3 | 本人ごとに、その人の平均の波形とゆらぎから作る | 本人の平均と共分散（個人の再現型） |

### 物差し

| 物差し | 測り方 |
|---|---|
| 本人との紐づき | 攻撃者は、全員（メンバーと非メンバー）の登録用の記録で学習した個人識別器を持つ。合成の被験者ごとに各拍の識別器の確率を平均し、登録された人ごとに「最もその人らしい合成の被験者」の確率を求める。これでメンバーかどうかを当てたときのAUCと経験的なεの下限。E3とcopyでは、合成の被験者が元の本人と判定された割合（source_top1）も |
| それっぽさ | 非メンバーの合成に使う側の記録（合成にも識別器の学習にも使っていない）と比べる。主成分（10個）の空間での最大平均差（MMD）、判別スコア（勾配ブースティングの正解率−0.5、被験者単位の5分割交差検証）、被験者ごとの平均の波形の分布のWasserstein距離（主成分3つの平均）、心拍間隔の分布のWasserstein距離 |
| 有用性（MIT-BIHのみ） | 正常拍（N）と心室性期外収縮拍（V）を、それぞれメンバーの拍から合成し（copyはメンバーの実データ）、合成で学習したロジスティック回帰を非メンバーの実データで評価したAUROC |

実行手順は次のとおり。

```bash
# ECG-ID（https://physionet.org/content/ecgiddb/1.0.0/）を data/ecgid/raw/ に、
# MIT-BIH（https://physionet.org/content/mitdb/1.0.0/）を data/mitdb/raw/ に展開しておく
uv run transyn ecg-linkage --dataset ecgid
uv run transyn ecg-linkage --dataset mitdb --beats 200
```

所要時間（CPU）は、ECG-IDが約5分、MIT-BIHが約30分。

### 外れた波形の人への紐づきの集中

外れ具合（被験者ごとの平均の波形の、集団で標準化した距離）の上位20%と、それ以外での紐づきのAUC（5通りの分け方の平均）。

| データ | 作り方 | 外れた人 | それ以外 |
|:--|:--|--:|--:|
| ECG-ID | E1 | 0.566 | 0.554 |
| ECG-ID | E2 | 0.601 | 0.526 |
| MIT-BIH | E1 | 0.764 | 0.549 |
| MIT-BIH | E2 | 0.859 | 0.600 |

外れた人は1回の分け方で9人前後（うちメンバーは4〜5人）なので、目安の値。

### 読み取り

- 個人の再現型（E3）は、合成の拍が本人の平均の波形の周りに出るので、識別器がそのまま本人を当てる。拍ごとのゆらぎは作り直しているが、本人の形の特徴は残る。1人あたりの拍が多いMIT-BIH（200拍）では、平均すると識別はさらに確実になった。
- E2は、被験者ごとの平均の波形を集団の分布から引き直すので、合成の被験者は特定の人に対応しない。ただし、分布の平均と共分散はメンバーの平均の波形から推定するので、外れた人がいるとその方向に分布が広がり、その人に似た合成の被験者が出やすくなる。MIT-BIHには不整脈で波形が大きく外れた人がいて、この効果が強く出た。
- E1でもMIT-BIHの外れた人に紐づいたのは、外れた人の拍が集団の平均と被験者内の共分散を引っ張り、合成の拍のゆらぎがその人の方向にも広がったためと考えられる。
- それっぽさの指標のうち、被験者ごとの形の分布の距離は、E2・E3が実データ並み（ECG-IDで0.60〜0.63）で、E1・E0は大きい（0.78〜0.80）。E1・E0は全員が似た形なので、被験者ごとの違いがない。
- 判別スコアは、同じ人の拍が学習と検証の両方に入らないよう被験者単位で分けた。分けない場合は、別の人の実データ同士でも0.42と出て、人の違いを見分けてしまっていた。
- 拍の分類の有用性がE1・E2で実データ以上だったのは、メンバーの実データには個人の波形の癖が入り、非メンバーの拍への当てはまりを下げていたためと考えられる。拍の種類の違いは集団の平均の形で十分に表せる。

## 公開への示唆

- 心電図の合成データで、本人ごとに作る（個人の再現型の）合成は公開してはいけない。実データとほぼ同じ確率で本人に結びつく。
- 集団の分布から作る合成でも、外れた波形の人（不整脈など）は紐づきうる。公開前に、個人識別器による照合攻撃を、外れた人に分けて確かめる必要がある。
- 拍の分類のような用途なら、本人の特徴を持たない合成（E1・E2）で有用性は保てる。それっぽさを上げるほど紐づきの危険が増えるので、見本として伝えたい性質に見合った作り方を選ぶ。
- 対策（k人の平均、雑音、外れた人の除外、差分プライバシーなど）の効果はGHE issue 18で確かめる。

## 制約

- 合成は拍の単位（R波の前後0.7秒）で、連続した波形や心拍間隔の時間構造（心拍変動）は作っていない
- 識別器は主成分＋線形判別分析で、心電図の生体認証の研究で使われる深層学習（CNN）より弱い可能性がある。より強い識別器では紐づきは大きく見える
- ECG-IDの記録は20秒と短く、1回目の記録から取れる拍は1人あたり平均24拍
- ECG-IDはI誘導、MIT-BIHはMLII誘導の1本だけ。多誘導の誘導間の関係は扱っていない
- MIT-BIHの201と202は同じ人の記録だが、別の人として扱った
- 有用性の評価は拍の分類（N・V）の1課題だけ
