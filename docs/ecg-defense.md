# 心電図の合成データの本人との紐づきへの対策

GHE issue 18の成果物。心電図の合成データは、本人ごとに作ると本人に結びつき、集団の分布から作っても外れた波形の人に紐づきが集中した（GHE issue 17、[ecg-linkage.md](ecg-linkage.md)）。対策を加えて、それっぽさ・有用性をどれだけ保ったまま紐づきを下げられるかを確かめた。

## 要点

1. **それっぽさを保ったまま紐づきを当て推量並みにできる対策は、なかった。** 対策なしを含む22の設定を「判別スコア（それっぽさ、0が本物並み）」と「紐づきのAUC（0.5が当て推量）」で並べると、判別スコアが0.25を下回る設定で紐づきが最も小さかったのは集団の分布から作る合成（E2）で、ECG-IDで0.545、外れた人では0.60だった。AUCが0.53を下回ったのは差分プライバシー（0.48〜0.52）だけで、その判別スコアは0.48〜0.50（ほぼ完全に見分けられる）だった。
2. **拍に雑音を足す対策は、拍の多いデータでは効かなかった。** 本人ごとの合成（E3）に0.2 mVの雑音を足しても、MIT-BIH（1人200拍）では元の本人と判定される割合が93%のままだった。識別器が多くの拍の確率を平均するので、拍ごとの白色雑音は打ち消される。ECG-ID（1人24拍）では86%から26%に下がった。
3. **外れた人の除外は、危険を他の人に移した。** 集団の分布から作る合成（E2）の前に外れ具合の上位20%を除くと、外れた人の紐づきはMIT-BIHで0.86から0.55に下がったが、それ以外の人では0.60から0.68に上がった。分布が典型的な人の周りに引き締まり、合成の被験者が実在のメンバーの近くに出やすくなるため。被験者の平均のまとめ（ミクロ集計）や主成分を減らす対策も、E2の紐づきを下げなかった。
4. **k人の平均は、本人の特定を大きく減らしたが、外れた人は守りきれなかった。** 本人ごとの合成で、本人に近いk人の平均の波形を使うと、元の本人と判定される割合はk=10でECG-IDが86%から5%、MIT-BIHが97%から8%になった。ただし外れた人の紐づきはMIT-BIHで0.80残った。
5. **差分プライバシーは、数十人ではそれっぽさと有用性を壊した。** データに依存しない基底（離散コサイン変換）で被験者ごとの寄与を有界にし、ε = 1〜8で作ると、紐づきは当て推量並み（AUC 0.48〜0.52）になったが、判別スコアは0.48〜0.50、拍の分類の有用性はAUROC 0.50〜0.51（当て推量）だった。
6. **集団の平均の形で作り、外れた人を除く設定が、釣り合いで最も良かった。** E1に外れ具合の上位20%の除外を組み合わせると、紐づきのAUCはECG-IDで0.551（外れた人0.538）、MIT-BIHで0.558（外れた人0.639）、拍の分類の有用性は0.813と全設定で最も高かった。代わりに、被験者ごとの波形の違いは持たない（全員が似た形）。

## 方法

GHE issue 17と同じデータ（ECG-ID 89人、MIT-BIH 43人）、メンバーの分け方（5通り）、攻撃（別の記録で登録した個人識別器による照合）、それっぽさと有用性の物差しを使った。外れた人は、被験者ごとの平均の波形の外れ具合の上位20%。

| 対策 | 中身 | 強さ |
|---|---|---|
| E3-kanon | 本人ごとの合成で、本人の平均の波形の代わりに、波形が近いk人（本人を含む）の平均を使う（k-匿名の考え方） | k = 2・3・5・10 |
| E3-noise | 本人ごとの合成の拍に白色雑音を足す | 標準偏差 0.05・0.1・0.2 mV |
| E2-trim | 外れ具合の上位の人を除いてから、集団の分布（E2）を推定する | 10%・20% |
| E2-agg | 被験者の平均の波形を、第1主成分の順に並べてk人ずつの組の平均に置き換えてから、集団の分布を推定する（ミクロ集計の簡略版） | k = 3・5 |
| E2-pc | 主成分を20個から減らして集団の分布を推定する | 3・5個 |
| E2-dp | 差分プライバシー付きのE2。基底はデータに依存しない離散コサイン変換（DCT）の先頭20個。被験者ごとの平均の係数（L2ノルム8まで）・拍ごとの残差（4まで）・心拍間隔（0.3〜2.0秒）を公開の定数で有界にし、6つの総和にガウス雑音を加える。会計はzCDP（δ = 10⁻⁵） | ε = 1・4・8、雑音なし |
| E1-trim | 外れ具合の上位の人を除いてから、集団の平均の形（E1）で作る | 10%・20% |

実行手順は次のとおり。

```bash
uv run transyn ecg-defense --dataset ecgid
uv run transyn ecg-defense --dataset mitdb --beats 200
```

所要時間（CPU）は、ECG-IDが約5分、MIT-BIHが約10分。

### 読み取り

- 紐づきとそれっぽさの関係は、作り方によらず同じ向きだった。合成の被験者の波形が実在の人に近いほどそれっぽく、近いほど識別器が誰かに結びつける。被験者ごとの違いを持つ合成（E2・E3系）でそれっぽさを上げると紐づきが増え、違いを持たない合成（E1系）は紐づきが小さいが、全員が似た形になる。
- 雑音の効き方がデータで違ったのは、攻撃者が使える拍の数の違いによる。1人24拍のECG-IDでは0.2 mVの雑音で本人の判定が26%に下がったが、200拍のMIT-BIHでは平均で打ち消された。公開する拍の数が多いほど、拍ごとの雑音は効かなくなる。
- 外れた人の除外は、除いた人の情報を合成に入れないので、その人は守られる。ただし残った人の分布が引き締まり、残った人への紐づきが増えた。MIT-BIHのE2-trim 20%では、外れた人の0.55と引き換えに、それ以外の人が0.68になった。
- k人の平均は、合成の1人が特定の1人に由来しないようにするが、外れた人はその近くのk人も似ていないので、平均しても外れた人の特徴が残る。
- 差分プライバシーの雑音は、44人前後の人数に対して大きすぎた。ε = 8でも、被験者ごとの形の分布の距離は雑音なしの2〜5倍になった。雑音なしでも、データに依存しない基底（DCT）は主成分より拍の形の再現が粗く、判別スコアが0.35〜0.40になった。
- E1-trimの有用性が最も高かったのは、拍の分類に必要なのが拍の種類ごとの平均の形で、外れた人の拍がそれを歪めていたためと考えられる。

## 公開への示唆

| 公開の目的 | 推奨する作り方 | 主張できる安全の根拠 |
|---|---|---|
| 拍の種類ごとの典型的な形を見せる、拍の分類の練習や手法の検証に使ってもらう | 集団の平均の形で作り、外れた人を除く（E1-trim 20%） | 照合攻撃でAUC 0.55〜0.56。外れた人でも0.54〜0.64 |
| 被験者ごとの波形の違いも見せる | 集団の分布から作る（E2）。外れた人への照合攻撃を必ず確かめ、外れた人が多いデータでは使わない | 照合攻撃で0.55〜0.64。外れた人では0.60〜0.86 |
| 個人ごとの合成（デジタルツイン） | 公開しない | – |

- 数十人の心電図で数学的な保証（差分プライバシー）を付けると、見本として使えない。保証を主張するには、他の研究のデータと合わせて人数を増やすなどの工夫が要る。
- 雑音を足す、外れた人を除く、k人の平均をとる、といった単純な対策は、それぞれ効く範囲が限られる。公開前には、今回の照合攻撃（別の記録で登録した識別器）と、外れた人に分けた評価を必ず行う。
- 公開する拍の数は少なくする。拍が多いほど、攻撃者は平均して本人の特徴を取り出しやすい。

## 制約

- 識別器は主成分＋線形判別分析。深層学習の識別器では紐づきが大きく見える可能性がある
- 外れた人の評価は、1回の分け方で9人前後（うちメンバー4〜5人）で、値は目安
- k人の平均は全体の距離での近い人、E2-aggは第1主成分の順に区切る簡略版で、厳密なミクロ集計（MDAVなど）ではない
- 差分プライバシーの有界化の定数（L2ノルム8・4）は筆者が決めた値で、狭く決めれば雑音は減るが切り詰めによる歪みが増える
- 合成は拍の単位で、連続した波形・心拍変動・多誘導の関係は扱っていない
