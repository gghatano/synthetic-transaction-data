# 学習人数が少ないときの生成モデル

GHE issue 3の成果物。研究室の実験は被験者数十人の規模になることが多い。見本用の合成データを作るときに、どの規模でどの方式が使えるか、少人数でコピーや外れた被験者の再現がどれだけ起きるかを確かめた。公開リポジトリの#15（学習716滞在）を、学習人数を絞って繰り返した。

## 要点

1. **どの人数でも、合成データは実データと見分けられた。** 要約特徴量による判別スコア（正解率−0.5）は、どのモデル・人数でも0.43〜0.49。実データの n 人を同じように比べると0.00〜0.04。学習人数を増やしても、見分けにくくはならなかった。
2. **DGANは少人数で時間構造をよく再現したが、学習データを覚えた。** 更新回数を24,000回にそろえたので、少人数ほど同じデータを何度も学習する。自己相関のずれは20〜100人で0.03〜0.06と実データ20人の標本（0.047）並みだったが、716人では0.13に戻った。20人の学習ではメンバーシップ推論のAUCが0.74（3シードで0.67〜0.80、理想は0.5）、学習データにごく近い合成系列が平均5.7%あった。50人で0.58、100人以上で0.48〜0.49。
3. **PARは人数を増やしても質が変わらなかった。** 被験者ごとの平均のずれは20人でも716人でも0.44〜0.51で、#15の滞在シャッフル（0.57）に近い。学習データを覚えることはなかった（AUC 0.48〜0.49）。
4. **VAR(1)は50人以上で安定した。** 被験者ごとの平均のずれは50〜716人で0.18〜0.25と3モデルで最も小さく、シード間のばらつきも小さい。20人ではずれが0.37（シード間の標準偏差0.14）に悪化した。メンバーシップ推論のAUCはどの人数でも0.47〜0.50。
5. **少人数では、条件で分けた群が数人になる。** 20人の学習で死亡退院が1人しかいない場合があり、VAR(1)は群ごとの共分散を推定できずに止まった（群をまたいでまとめた共分散を使うよう修正した）。この場合、合成データの「死亡した被験者」の群の平均は、実在の1人の値そのものになる。

## 方法

- データ: eICU Demo v2.0.1の定期バイタル（#15と同じ前処理・A/B/C分割、A 716・B 354・C 352滞在）
- 学習: Aから n = 20・50・100・300・716 人を抜き、3シード（0〜2）で学習する
- 生成数: n によらず716人（#15と同じ）にそろえ、指標のぶれを n の違いと切り分ける

| モデル | 設定 |
|---|---|
| var1 | #15と同じ。死亡退院の有無で群を分け、群の人数が次元（7）以下なら群をまたいでまとめた共分散を使う |
| par | SDV PAR、200エポック |
| dgan | gretel版DGAN、バッチ64、更新回数24,000回（#15のバッチ64・2,000エポックと同じ）。20人では24,000エポック、716人では2,000エポック |

評価は#15の指標を、比較の相手を変えて使った。

| 軸 | 比べる相手 | 理由 |
|---|---|---|
| 忠実度（Marg, Corr, ACF, PSD, StayMean, StayStd, Disc, Mortality） | 学習に使っていない実データC | 少人数の学習データと比べると、覚えたモデルほど良く見える |
| 有用性（TSTR_AUROC） | 評価用B | #15と同じ |
| プライバシ（DCRRatio, MIA, NearCopy） | 学習した n 人（メンバー）と評価用B（非メンバー） | 学習に使った人だけがメンバー |
| 外れた被験者の近接比（OutlierProx） | 同上 | 下記 |

外れた被験者の近接比は、滞在ごとの平均の標準化距離で上位10%（最低2人）を「外れた被験者」とし、外れた学習被験者から最も近い合成系列までの距離の中央値を、外れた非メンバーでの同じ値で割ったもの。1を大きく下回ると、外れた学習被験者の近くに合成系列が出ている。

基準として、学習に使っていない実データ n 人（Bから抜く）をそのままCと比べた値（real-n）を並べた。real-nの有用性はCで評価した。

実行手順は次のとおり。

```bash
uv run transyn vitals-prepare
for n in 20 50 100 300 716; do
  for s in 0 1 2; do
    for m in var1 par dgan; do uv run transyn --seed $s smalln-run $m --n $n; done
  done
done
uv run transyn smalln-evaluate
```

所要時間（CPU、4本並行）は、VAR(1)が1本5〜13秒、PARが6分（20人）〜15分（716人）、DGANが13〜24分。

### 読み取り

- 判別スコアは、どのモデルも学習人数を716人まで増やしても0.43を下回らなかった。#15と同じく、要約特徴量の分類器が9割以上の正解率で見分ける。少人数でも多人数でも、「実データと見分けがつかない合成データ」には届かない。
- DGANの時間構造の良さは、少人数での学習回数の多さ（20人で24,000エポック）から来ている。同じ設定で716人では2,000エポックになり、自己相関もスペクトルも悪化した。少人数での良さは、学習データを覚えることと引き換えだった。
- VAR(1)は滞在内の変動を定常な1次の自己回帰で作るので、自己相関のずれ（約0.18）は人数によらず変わらない。被験者ごとの平均・ばらつきは群ごとの多変量正規分布で作るので、50人程度でおおむね推定できる。
- 学習データにごく近い系列の割合（NearCopy）は、しきい値を「評価用Bから学習データまでの距離の1パーセンタイル」で決めている。学習人数が少ないほどこの距離が大きくなり、しきい値が緩くなる。VAR(1)の20人で2.9%と出たのはこのためと考えられ、人数をまたいだ比較にはメンバーシップ推論のAUCのほうが向く。
- 外れた被験者の近接比は、DGANの20〜100人で0.89〜0.91、それ以外は0.88〜1.47で、外れた被験者に特有の近さははっきり見えなかった。
- 20人の学習・シード1では死亡退院が1人だった。VAR(1)の合成データの死亡した被験者35人の平均は、心拍数97・SpO2 92・呼吸数29で、実在の1人（88・96・28、76歳）を中心に、まとめた共分散で広く散った。合成した被験者からその1人までの標準化距離の中央値は2.05で、学習データ全体からその人までの中央値2.3より少し近い程度だった。

## 見本用データへの示唆

- 学習人数が数十人なら、VAR(1)のような統計モデルを第一候補にする。被験者ごとの違いを最もよく保ち、学習データを覚えない。ただし20人程度では推定がシードで大きくぶれる。
- 深層モデル（特にDGAN）を少人数で長く学習させると、時間構造は良く見えるが学習データを覚える。少人数で使うなら、学習回数を人数に合わせて減らし、メンバーシップ推論で確かめる必要がある。
- 条件（群）ごとに合成する場合、少人数では群が数人になり、群の平均がその人たちの値になる。見本用データでは、少数の群を条件にしない、あるいは群をまとめる。
- どの方式でも、合成データは実データと見分けられる。見本用データは「データの形と典型的な変動を伝えるもの」として扱い、分析の代わりにはしない（GHE issue 1、[synthetic-inference.md](synthetic-inference.md)）。

## 制約

- DGANは更新回数を固定した。人数に合わせて更新回数やエポック数を調整すれば、少人数での記憶と時間構造の良さの釣り合いは変わる
- 生成数を716人にそろえたので、少人数の学習から多数を生成している。見本用データのように少数だけ生成する場合、プライバシの指標は変わり得る
- 判別スコアは要約特徴量に基づく
- 変数3つ・12時間の系列に限る。欠測は線形補間している
- 3シードのみ
