# 見本用データの開示リスクへの対策と保証

GHE issue 14の成果物。見本用データのL3・L4（被験者ごとの違いを保つ段階）では、外れた被験者が学習に入っていたかを狙い撃ちで当てられた（GHE issue 13、[attacks.md](attacks.md)）。この漏れへの対策を2つ試し、「安全な合成データである」と言える根拠を整理した。

合成データの安全の根拠には、性質の違う2種類がある。

- **数学的な保証（差分プライバシー）**: 生成の手順に雑音を入れ、被験者1人を入れ替えても出力の分布が最大 e^ε 倍しか変わらないことを示す。どんな攻撃に対しても成り立つ
- **経験的な確認（攻撃による監査）**: 試した攻撃の成功率を示す。試していない攻撃に対しては何も言えない

英国のICO、EUのEDPB（2026年の指針案）は、合成データを自動的には匿名とみなさず、個別の評価を求めている。日本では、元データから作った合成データの法的な位置づけについての個人情報保護委員会の公式見解は、調べた範囲（2026年10月）では見つからなかった。

## 要点

1. **差分プライバシーを入れると、どのεでも外れた被験者への狙い撃ちは当て推量並みになった。** 20人・50人の学習、ε = 0.5〜8で、外れた被験者を狙ったAUCは0.50〜0.57、実測したεの下限は最大0.19だった。雑音を入れない同じ手順では、AUC 0.81〜0.93、εの下限の最大2.0〜3.0。どの条件でも、実測したεの下限は理論上のεを超えず、実装と会計に矛盾は見つからなかった。
2. **ただし数十人の学習では、差分プライバシーで見本の質が大きく落ちた。** 被験者ごとの平均のずれ（実データCとのWasserstein距離）は、716人の学習ならε=8で0.18・ε=4で0.28と雑音なし（0.12）に近いが、20人・50人ではε=8でも1.5〜1.7（雑音なしは0.15〜0.24）。雑音は人数によらない大きさで総和に加わるので、人数が少ないほど相対的に大きくなる。死亡退院による心拍数の差（L4）は、シードごとに数十bpmぶれた。
3. **外れた被験者を除いてから推定すると、狙い撃ちは大きく弱まった。** 学習データのうち外れ具合の上位10%を除いてL3を作ると、外れた被験者を狙ったAUCは20人で0.79から0.58、50人で0.70から0.55、200人で0.59から0.53になった。L4でも、20人で0.82から0.56、50人で0.74から0.57、200人で0.62から0.56になった。ただし、どの段階・人数でも漏れが少し残り、εの下限が正の標的が10人中0〜4人いた（最大0.56、L3の20人）。除外は攻撃を大きく弱めるが、保証にはならない。
4. **外れた被験者の除外は、見本の忠実度もかえって良くした。** 716人の学習で、被験者ごとの平均のずれは0.176から0.105、ばらつきのずれは0.198から0.031（実データ同士と同じ）、スペクトルのずれは0.98から0.27になった。外れた被験者が多変量正規分布の推定を歪めていたため。代わりに、極端な被験者は見本に出てこない。
5. **公開の生理的な範囲の端と同じ値は、極値の再現として数えないよう公開前チェックを直した。** 呼吸数の上限60のように、切り詰めで誰にでも出る値まで数えていた。直した定義で、既定（学習データの最小・最大で切り詰め）の見本では特定の人を表す極値がL1〜L4で1.0〜3.0個出た（GHE issue 9の報告は1.0〜4.0個）。分位点で切り詰めた版は0個のまま。

## 方法

### 差分プライバシー付きの生成

- 隣接関係は「被験者1人を別の1人に入れ替える」（人数 n は公開とみなす）。プライバシの単位は被験者
- 被験者ごとの統計量 u（3変数の平均・log標準偏差、年齢、死亡退院の8次元）を、データから決めない公開の範囲で[0, 1]に正規化する
  - 平均: 心拍数40〜160、SpO2 80〜100、呼吸数5〜40
  - 標準偏差: 心拍数0.2〜25、SpO2 0.05〜10、呼吸数0.2〜15
  - 年齢18〜90
- 雑音を加えて出す量は4つで、それぞれにガウス機構を当てる
  - u の総和（L2感度 √8）
  - u uᵀ の総和（8）
  - 被験者内で標準化した系列のラグ0・ラグ1の共分散行列の総和（各 6.06。標準化した系列の共分散の成分は |·| ≤ T/(T−1) < 1.01）
- 会計はzCDP。ε・δ（δ = 10⁻⁵）からρを求め、4つの量に等分する。ε = 8で雑音の標準偏差は u の総和に3.9、u uᵀ の総和に11.0
- 雑音を加えた量から平均・共分散・VAR(1)の係数を推定し（後処理なのでεは変わらない）、L3は属性と独立に、L4は死亡退院の値で条件づけた多変量正規分布から被験者ごとの性質を引く
- 生成後の値は公開の生理的な範囲（#15の範囲）で切り詰める。学習データの分位点はDPでないので使わない
- ε = 0.5・1・2・4・8 と、雑音を入れない同じ手順（ε = ∞）で比べた

### 外れた被験者の除外

学習データのうち、被験者ごとの特徴量（3変数の平均・log標準偏差）の標準化距離が上位10%の被験者を除いてから、L3・L4の統計量を推定する。値は分位点で切り詰める（公開の既定）。除く被験者の選び方は学習データで決めるので、差分プライバシーの保証はない。

### 監査と評価

- 監査: GHE issue 13の狙い撃ちのメンバーシップ推論（標的ごとに200回、平均的な被験者5人・外れた被験者5人）
- 忠実度: 学習データA（または A から n 人）で716人分を3シードで生成し、実データCと比べる（#15の指標）

実行手順は次のとおり。

```bash
uv run transyn vitals-prepare
uv run transyn dp-evaluate
for n in 20 50; do uv run transyn dp-audit --n $n --reps 200; done
for n in 20 50 200; do uv run transyn attacks-targeted --n $n --reps 200 --levels L3 L4 --trim 0.1; done
uv run transyn showcase-evaluate
```

所要時間（CPU、並行実行）は、DPの評価が約15分、DPの監査が1本約20分、除外の監査が1本約30分（大半はL4の生成）。

### 読み取り

- 差分プライバシーで攻撃が当て推量並みになったのは、外れた1人の影響が雑音に埋もれるため。理論上はε=8でも1人の有無で出力の確率が最大約3,000倍変わりうるが、実際の攻撃はその上限よりはるかに弱かった。保証は最悪の場合の上限で、今回の攻撃はその上限に近づかない。
- 少人数で質が落ちるのは、雑音の大きさが総和の感度（公開の範囲の幅）で決まり、人数によらないため。改善の方向は、データを見ずに決められるものに限られる。公開の範囲を狭くする、雑音を加える統計量を減らす（共分散を対角だけにする）、複数の研究のデータを合わせて人数を増やす、など。
- 外れた被験者の除外は、狙われやすい人を生成に使わないことで攻撃を弱める。ただし除く人の選び方がデータで決まり、選ばれなかった人が誰かという情報が残るので、20人の学習では漏れが残った。数学的な保証はない。
- 除外で忠実度が良くなったのは、外れた被験者が多変量正規分布の平均と共分散を引っ張っていたため。Wasserstein距離は分布の大部分の一致を見るので、裾の被験者がいなくなった影響は小さく出る。見本で「極端な被験者が存在すること」を伝えたい場合には向かない。

## 見本用データの公開への示唆

| 学習人数 | 推奨 | 主張できる根拠 |
|---|---|---|
| 数十人 | L2（被験者内の時間変化まで）を公開する。被験者ごとの違いを見せたい場合は、L3に外れた被験者の除外を加え、狙い撃ちの監査を通す | 試した攻撃（狙い撃ち・属性推論・部分系列）で当て推量並み（経験的な確認） |
| 数百人以上 | L3・L4を差分プライバシー付き（ε = 4〜8）で公開する | 差分プライバシーの数学的な保証（ε, δ = 10⁻⁵）と、監査で実測したεの下限が理論値を超えないこと |

- どの場合も、公開前チェック（表示・開示リスク・構造・文書化）に狙い撃ちのメンバーシップ推論を加え、保つ性質・保たない性質・プライバシの根拠の種類を文書に書く。
- 「法的に匿名」とは書かない。倫理審査委員会と個人情報の取扱い部門で、データセットごとに確認する。

## 制約

- 差分プライバシーは L3・L4 の統計量に雑音を加える方式だけ。深層生成モデルのDP学習（DP-SGD）は試していない
- 公開の範囲は筆者が一般的な目安として決めた値で、狭く決めれば雑音は小さくなる
- 監査の攻撃は最近傍距離に基づく。より強い攻撃（尤度比、シャドーモデルの分類器）での監査はしていない。実測したεの下限は、しきい値を同じ試行から選んだ目安
- 外れた被験者の除外の割合は10%の1通りだけ
- 心電図による個人識別の攻撃は試していない
